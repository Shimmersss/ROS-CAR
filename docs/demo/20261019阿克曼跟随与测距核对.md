# 2026-10-19 阿克曼跟随控制与测距核对

## 测距核查结论

对完整录像 `20261019-184852-guard-fixed-30s`，按每条 TargetState 的 observation_stamp、track_id 精确配对真实 PersonState：958条新鲜有效目标全部完成同帧/同轨迹匹配，距离0.309–1.040米，中位0.509米，全部小于1.3米。其中337条身体深度来源为pose_anchors，621条为regions；身体当前Z深度与过滤后的目标Z差值中位约1.5毫米、最大54.3毫米，符合滤波前后不同的语义。

核对1/15/35/65秒原图，白衣主人确实很近，后续大部分身体在画面边缘。车端固定驱动使用 `PIXEL_FORMAT_DEPTH_1_MM`，16UC1输入乘0.001转换米与之匹配，没有找到十倍单位或光学XY/前向Z混用的证据。

这些只证明链路内一致和抽样画面相符，不能代替卷尺标定，不能宣称绝对测距已验收。没有证据支持修改比例或把近距离读数强行变大，本轮不改测距算法、不放宽深度门槛。此前将不动首先归为“测距有误”的判断过早；在这些帧上不发前进本来符合1.3米要求。

## 控制律改动

新增 `FollowConfig.ackermann` 默认false，通用入口及旧模式保持兼容。demo通过 FOLLOW_ACKERMANN=true 显式开启：

- 距离不超过1.3米及距离死区时，两轴归零，不再输出零前进加非零角速度。
- 距离足够且目标位于前半平面时，前进速度按距离误差限制，再乘cos(偏角)，转向时减速。
- 角速度受原角速度上限和 `abs(w) <= v/min_turn_radius_m` 双重限制，转向方向仍保持原光学坐标约定；不倒车、不为转向强加最低前进速度。
- 前半平面之外停车，不尝试原地调头。

软件转弯半径下限0.4米，复用当前demo相对运动/语音适配器的暂定软件值，**不是已实测的底盘最小转弯半径**。仍须现场核对弧线方向和转弯能力。距离1.3米仍沿用现有相机目标代表点语义，不擅自改为后轴或脚下距离。

另将跟随器20Hz请求定时器改用STEADY_TIME，与guard一致；ROS时钟暂停/调整时仍执行请求与零速更新。目标的真实接收龄期、传感器时间戳、授权心跳和跌倒门控保持，不延长200ms请求超时或0.6秒目标宽限。

新增只读[跟随状态接口](../interfaces/跟随状态接口.md)，解释距离已够、目标无效、未授权、跌倒暂停等原因；录制器一并保存，不新增速度出口。
