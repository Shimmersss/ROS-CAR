# 小车语音控制使用说明书

需要从程序发送文字让小车播报，可调用 `/voice/say`，无需先唤醒。完整命令见 [文字播报 ROS 接口](文字播报ROS接口.md)。

版本：2026-10-04 · 适用于 `codex/voice-tongue-integration` 的固定规则语音控制与舌苔检测流程。

本说明书介绍当前代码支持的口令和使用方法。新程序尚未部署到小车，运动总开关、转向标定和微动标定默认关闭。以下行驶操作用于完成实车验收、由调试人员配置并启用相应功能之后；当前默认配置可以进行唤醒、查询和识别验证，不会因为说出行驶口令就开启运动。

舌苔模块也默认关闭，需要调试人员启用并确认相机、播报、停车保护及舌象服务器就绪。它在车辆保持静止时工作，不需要开启手动控制。完整使用步骤见第 6 节。

## 1. 第一次使用：记住这个顺序

**手动行驶：系统就绪 → 小车唤醒 → 开启手动控制 → 等待授权成功 → 说一个动作 → 用完停车。**

**舌苔检测：模块就绪且车辆静止 → 小车唤醒 → 舌苔检测 → 按提示配合拍摄 → 听结果 → 重拍或退出。**

先请调试人员确认程序、麦克风、扬声器和底盘已就绪，并说明哪些功能已验收启用。基础练习先使用直行；转弯、微动和人体跟随需要各自的实车条件满足后再使用。

| 操作 | 你说的话 | 接下来怎么做 |
|---|---|---|
| 唤醒 | **小车唤醒** | 等“已唤醒，请说指令”播报结束 |
| 请求手动授权 | **开启手动控制** | 等“手动控制已授权”；授权失败时先处理提示 |
| 短时前进 | **前进一秒** | 等动作完成和播报结束，再说下一条 |
| 短时后退 | **后退一秒** | 小车按本条指令的时长执行 |
| 普通停车 | **停车** | 确认小车停住；成功后手动/跟随授权都会撤销 |
| 舌苔检测（可选） | **舌苔检测** | 模块启用后自动检测一次；不需要驾驶授权 |
| 结束交流 | **退出语音** | 结束普通会话，有检测任务时同时退出；行驶时先完成停车 |

“已接受运动请求”表示软件接收了指令，实际动作是否完成要观察小车。没有听到授权成功，或收到拒绝提示时，先查询状态，不继续发送行驶口令。

## 2. 怎么说，更容易被正确识别

- 面向麦克风，用正常音量清楚说话。实际可用距离需要现场测试，本说明书不承诺固定识别距离。
- 一次只说一个动作，例如“前进一秒”。说完稍停，当前程序以约 0.6 秒的静音判断一句话结束；整句话保持连贯，避免在动作与参数之间长时间停顿。
- 普通指令等小车播报结束再说。紧急停车词可以在播报期间喊出，独立急停通道仍在监听。
- 一次交互后，默认有约 8 秒可以继续说下一条普通指令。超过窗口，再说“小车唤醒”；说“不用了”“退出语音”或“休眠”可以结束会话。
- 重复唤醒会刷新会话。正在等待驾驶授权结果时先等结果，避免重新唤醒取消尚未完成的授权请求。舌苔检测期间重新唤醒不会退出检测，也不会打断检测提示或结果播报，此时可能没有额外的唤醒播报。
- 尽量使用下表中的直接口令。询问、转述或一口气说多个动作，会被固定规则拒绝；行驶否定句不执行动作。舌苔模式支持“不要检查舌苔”作为取消口令，详见第 3.3 节。

**8 秒是听下一条指令的窗口。** 每条行驶指令有自己的持续时间；跟随也不会因为会话过期而自动结束。需要停止运动时，应明确停车。

舌苔检测同样不会因普通会话超时而取消。结果播报结束并进入等待下一步的阶段后，程序重新开放一次约 8 秒的续聊窗口，方便说“重新拍照”或“退出舌苔检测”；再超时就重新唤醒，程序不会一直保持普通监听。

## 3. 常用口令速查

### 3.1 唤醒、授权和状态查询

| 想做什么 | 推荐口令 | 其他支持说法 | 说明 |
|---|---|---|---|
| 唤醒 | 小车唤醒 | — | 打开会话，保持原有已成功取得的运动许可；唤醒本身不授予许可 |
| 开启手动控制 | 开启手动控制 | 进入手动模式、切换到遥控模式 | 先停车切换模式，再检查并申请手动授权 |
| 开启跟随 | 开始跟随 | 开始跟随我、跟我走 | 需要有效的视觉目标及跟随条件，详见第 5 节 |
| 查询状态 | 查询状态 | 当前状态、小车现在是什么模式 | 报告模式、授权状态，以及当前有数据的电压/目标信息 |
| 查询电池信息 | 查询电量 | 电量多少、查询电池电压 | 当前有电压数据时报告伏特值，尚未提供可靠的电量百分比 |
| 查询目标 | 现在锁定了目标吗 | 是否在跟随、有没有锁定目标 | 返回当前状态信息，目标有效不等于已经获得运动授权 |
| 结束语音会话 | 退出语音 | 不用了、休眠 | 关闭普通会话，同时退出正在执行的检测模式；行驶时仍应先明确停车，不是关机口令 |

查询和模式口令应在普通会话中使用。一次切换模式会撤销旧许可并清除旧请求，需要等新的授权成功。

### 3.2 手动行驶

以下口令需要已经获得手动授权。

| 想做什么 | 推荐口令 | 效果及前提 |
|---|---|---|
| 前进 | 前进一秒 | 按配置速度向前行驶一秒 |
| 后退 | 后退一秒 | 按配置速度向后行驶一秒；也支持“倒车一秒” |
| 指定前进速度 | 前进速度零点一米每秒一秒 | 请求以 0.1 m/s 前进一秒 |
| 指定后退速度 | 后退速度零点一米每秒一秒 | 请求以 0.1 m/s 后退一秒，速度数值说正数即可 |
| 左转 | 左转一秒 | 向前走一段左弯曲线；需要转向参数已实车验收 |
| 右转 | 右转一秒 | 向前走一段右弯曲线；需要转向参数已实车验收 |
| 小幅前进 | 前进一下 | 微动；需要微动参数已实车验收 |
| 小幅后退 | 后退一下 | 微动；需要微动参数已实车验收 |
| 小幅转弯 | 左转一下、右转一下 | 分成两条独立口令使用；需要转向和微动均已验收 |

当前配置中，不说速度的普通直行请求默认使用 0.2 m/s，不说时长的普通动作默认持续 2 秒。软件允许直行速度大于 0、最高 0.2 m/s；单条动作时长为 0.05～2 秒。最终可用参数以实车验收配置为准，保护节点也可能拒绝或限制运动。

小车按阿克曼底盘处理，转弯会同时向前移动，不能原地旋转。口令中的转弯时长不代表转过指定角度，目前不支持“左转九十度”。

“一下”“一点”“稍微”会被当成微动要求。当前微动默认未启用，候选参数为 0.05 m/s、0.5 秒，实际位移尚未验证。基础练习使用“前进一秒”，待微动验收后再使用“前进一下”。

动作按时结束后，手动授权通常仍然保留，可以在会话内继续下一条；明确说“停车”则撤销授权，再次运动需重新开启手动控制。按时间执行不保证精确距离，目前不支持“前进一米”。

### 3.3 舌苔检测

以下口令需要舌苔模块已启用，并在唤醒后的普通会话中使用。普通口令等播报结束再说。

| 想做什么 | 推荐口令 | 其他支持说法 | 说明 |
|---|---|---|---|
| 开始检测 | 舌苔检测 | 舌苔判断、开始舌苔检测、检测舌苔、检查舌苔 | 自动进入模式并检测一次，不需要再说“拍照” |
| 重新检测 | 重新拍照 | 重新拍摄、重新检测舌苔 | 拍摄一张新图并重新提交；已有检测在等待时先取消旧请求 |
| 再听一遍结果 | 播报检测结果 | 播报上次结果、播报舌象结果 | 重播当前会话可用的成功或部分不确定结果，不重新拍照上传 |
| 退出检测，保留语音会话 | 退出舌苔检测 | 退出舌苔判断、取消舌苔检测、取消舌苔判断、退出当前模式 | 取消未完成检测、清理模式，小车保持空闲且未授权 |
| 取消检查 | 不要检查舌苔 | 取消检查 | 不会启动拍摄；已有舌苔模式时请求退出 |
| 退出检测并结束交流 | 退出语音 | 不用了、休眠 | 同时退出模式和关闭普通监听 |

单独说“拍照”没有对应操作。已在舌苔模式中时，再说“舌苔检测”不会自动重拍；要获取新结果，请说“重新拍照”。未进入模式时，重拍和重播口令也不会自动开启检测。

重拍开始后，前一次的可重播结果会清空。如果新检测失败或被要求重拍，不能通过“播报检测结果”听到旧的成功结果；退出模式后也不保留本会话的重播缓存。

## 4. 停车、急停和恢复

### 普通停车

在普通会话中、播报结束后说 **“停车”**。成功后，小车停车并撤销当前手动或跟随授权。继续使用时，重新唤醒（会话过期时）、说“开启手动控制”或“开始跟随”，等待授权成功。

如果正在舌苔检测，“停车”也会取消检测并退出模式。若只想结束检测、继续交流，可以说“退出舌苔检测”。

### 紧急停车

直接喊 **“停止”**。独立急停通道也监听 **“停下”“急停”“别动”**，设计上无需唤醒，在播报和会话外仍持续工作。

这四个词被独立通道检出后都会进入锁存急停，包括“停止”。因此喊“停止”后，可能需要复位才能继续行驶。独立通道检测关键词，不理解整句的否定或引用；车辆工作时，朗读或播放这些词也可能触发停车。

在舌苔检测期间检出这些词，也会取消检测和任务播报，丢弃未完成请求的迟到结果。退出检测不会解除急停锁存。

目前合成回放存在漏检：包括“急停”“别动”未检出，以及同一“停止”在不同流偏移下漏检。真人、运动噪声和播报双讲测试仍待完成，不能依赖语音作为唯一的停机方式。语音未生效时，应立即使用现场已确认的硬件停机方式；硬件停机装置的具体位置和方法由现场调试人员说明。

### 从锁存急停恢复

确认造成停车的情况已经处理、现场允许继续操作后，按顺序执行：

1. 说“小车唤醒”，等播报结束。
2. 说 **“解除紧急制动”**，等复位成功。
3. 说“查询状态”，确认当前未授权。
4. 说“开启手动控制”或“开始跟随”，等授权成功。
5. 再发送运动指令。

复位只解除锁存，车辆不会自动恢复原动作。使用准确口令“解除紧急制动”，避免说“解除急停”再次触发急停关键词。普通停车、模式切换和重启程序都不能解除急停锁存。

如果准备继续舌苔检测，在复位成功且急停识别通道恢复正常后，再说“舌苔检测”；不需要取得驾驶授权，之前取消的检测也不会自动重试。

### 从故障停车恢复

音频断流、急停通道异常、请求或感知数据过期等情况，可能使已授权系统进入故障状态。先请调试人员排除原因，再唤醒并说 **“复位故障”**。收到复位成功后重新选择模式、取得授权。原因仍存在时，复位或授权会被拒绝；不能通过反复发口令绕过。

## 5. 怎么使用人体跟随

跟随功能要求视觉系统提供有效的已锁定目标，并完成测距、安装、底盘及保护参数的实车验收。

1. 请调试人员确认当前锁定的是准备跟随的人，可以在 Foxglove 或状态反馈中核对目标。
2. 说“小车唤醒”，等播报结束。
3. 说“查询状态”，确认目标和控制状态。
4. 说“开始跟随”，等“跟随控制已授权”。授权成功且目标有效后，小车可能立即开始跟随，无需再说“前进”。
5. 要结束跟随，在普通会话内说“停车”；紧急情况直接喊急停词。

“跟随我”“跟我走”是开启跟随的口令，车辆跟随的是视觉系统当前锁定的目标。当前没有通过声纹识别说话者，也没有用说话方向自动选中对应的人。

目标丢失或数据失效时，跟随请求会变为零，保护节点可能进入故障。目标重新出现不代表自动恢复许可；先查询状态，再按提示处理。要改用方向口令，先说“开启手动控制”并等授权成功。

## 6. 怎么使用舌苔检测

### 6.1 第一次检测

先请调试人员确认舌苔模块已启用，车辆已经停稳，相机能获取清晰的彩色画面，扬声器和舌象服务器可用。进入检测会撤销原有手动或跟随许可，检测模式保持期间会拒绝行驶和新的运动授权。

1. 说 **“小车唤醒”**，等普通唤醒播报结束。
2. 说 **“舌苔检测”**。程序先请求停车、进入检测模式并检查服务；等拍摄提示，不要再发驾驶口令。
3. 听到“请正对相机，伸出舌头，保持不动”后，按提示配合。程序等待这段提示完整播放，再留约 2 秒准备时间，随后获取一张新照片；不需要另外说“拍照”。
4. 等待服务器判断和小车播报结果。判断可能超过 8 秒，普通会话超时不会取消本次检测。
5. 播报结束后，说“重新拍照”“播报检测结果”或“退出舌苔检测”。普通会话过期时先重新唤醒；用完也可以直接说“退出语音”，同时结束检测和交流。

相机拍到的原始彩色图片会发送到配置的舌象服务器处理。本地默认不保存图片，会记录结果；是否保存图片和服务器如何存储，由调试人员按实际配置说明。

### 6.2 等待、重拍和退出

检测提示与结果播报期间，普通语音识别会抑制结果。等播报结束再说重拍或退出；紧急停车通道仍在工作。

云端判断尚未返回时，也可以说“重新拍照”或“退出舌苔检测”。如果普通会话已过期，先重新唤醒，再说口令。重拍会取消旧请求并重新走提示、准备、拍摄和判断流程；旧请求晚到的结果不会混入新结果。

普通 8 秒监听超时只暂停听指令，**舌苔模式仍然保持停车**。再次唤醒不会退出检测；用完要明确说“退出舌苔检测”或“退出语音”。退出后小车仍未授权，不会恢复之前的跟随；要行驶，重新选择驾驶模式并等授权成功。

“退出舌苔检测”保留普通语音会话，“退出语音”同时关闭普通会话。取消后客户端不再采用未完成结果，但服务器已经开始的处理可能继续运行；不要把退出理解为删除服务器上的图片或记录。

### 6.3 怎么理解结果和失败提示

当前程序播报八项舌象特征：舌色偏淡、舌尖或舌边偏红、红点、瘀斑、裂纹、齿痕、厚苔和黄苔。一张图片可能同时出现多项特征；“部分特征暂不确定”时可以重拍。

“没有明确检出这八项舌象特征”表示这次模型没有给出明确阳性特征，不等于身体健康；没有检出黄苔或厚苔，也不推导成白苔或薄苔。程序目前不提供疾病诊断或治疗建议，分类准确率仍待真实图片验收。

图片不清晰、服务繁忙、网络超时或结果不完整时，程序会提示本次未完成或要求重拍。按提示调整拍摄或请调试人员排查后，再说“重新拍照”。没有可用结果时，“播报检测结果”会提示没有可重播的成功结果，不会把失败当成“八项都未检出”。

## 7. 常见问题

| 现象 | 可能原因和处理方法 |
|---|---|
| 唤醒了，但小车不动 | 唤醒没有授予运动许可；当前源码默认关闭运动，需先由调试人员完成配置和验收 |
| 提示“请先完成手动模式授权” | 当前未授权或处于跟随模式；开启手动控制并等成功反馈 |
| 提示“授权等待超时”或控制服务不可用 | 必要节点、状态或零请求尚未就绪；交给调试人员检查后重新发起授权 |
| 前进能用，左转或“一下”被拒绝 | 对应转向/微动标定未启用；先使用已验收的普通直行口令 |
| 播报时说普通指令没反应 | 普通识别会丢弃播报期间的结果；等播报结束再说，紧急情况使用独立急停词 |
| 一段时间后普通口令没反应 | 约 8 秒的会话窗口可能已过；重新说“小车唤醒” |
| 停车后再说“前进”被拒绝 | 停车撤销了授权；若是急停锁存，先复位，再重新授权 |
| “电量”没有百分比或没有电压 | 目前只在收到电压数据时播报伏特值；缺数据时不会编造电量 |
| 提示语句不明确 | 一次只说一个直接口令；取消检测时使用第 3.3 节的明确取消说法，避免询问、转述或混合多个操作 |
| 收到“已接受运动请求”，却没有实际移动 | 该反馈仅表示适配节点接收了请求；最终保护或硬件仍可能阻止运动，请查询状态并让调试人员检查 |
| 说“舌苔检测”却没有进入检测 | 舌苔模块默认关闭，也可能是会话已过期或服务未就绪；先重新唤醒，仍失败则请调试人员核对模块和相机/服务器 |
| 提示“执行模式正在保持停车” | 当前检测模式或其停车保持尚未结束；先退出检测、等退出反馈，再重新申请驾驶授权 |
| 检测超过 8 秒还没有结果 | 8 秒限制普通监听，不是检测时限；继续等待，要取消则重新唤醒并说“退出舌苔检测” |
| 提示图片不清晰或没有获得完整结果 | 按拍摄提示调整后重拍；反复失败时请调试人员检查画面、光照、网络和服务器版本 |
| 重拍失败后听不到上一次的结果 | 重拍会清空旧的可重播缓存；重新检测成功后才有本次可重播结果 |
| 再说“舌苔检测”没有重新拍摄 | 同一模式重复进入不会重拍；使用“重新拍照” |
| 退出检测后小车没有恢复跟随 | 属于当前正常行为；退出保持未授权，确认条件满足后重新说“开始跟随”并等授权成功 |

## 8. 当前不支持的用法

| 说法 | 为什么不执行 | 可用替代 |
|---|---|---|
| 能不能前进？ | 属于询问 | 前进一秒 |
| 不要前进、他说前进 | 属于否定或转述 | 有意行驶时直接说单一动作 |
| 先前进，再左转 | 同一句包含多个动作 | 分别发两条指令，逐条等待反馈 |
| 前进一米 | 尚未接入里程计距离闭环 | 前进一秒；实际距离需观察 |
| 左转九十度、原地左转 | 未提供角度控制，阿克曼底盘不能原地旋转 | 已验收后使用左转一秒 |
| 去客厅、去充电点 | 语音入口尚未接入地点映射和导航目标 | 当前没有对应语音替代功能 |
| 行驶时用“退出语音”代替停车 | 在手动/跟随场景中，结束普通会话不撤销已成功取得的运动许可；舌苔模式会同时退出检测 | 行驶时先“停车”并确认停住，再“退出语音” |
| 能不能检查舌苔？、他说舌苔检测 | 属于询问或转述，不触发检测 | 舌苔检测 |
| 先检查舌苔再前进 | 同一句包含不同操作，检测模式也禁止运动 | 分别操作；退出检测后重新取得驾驶授权 |
| 单独说拍照 | 没有对应的单独拍照口令 | 首次说“舌苔检测”；模式内说“重新拍照” |

## 9. 完整使用示例

### 9.1 手动行驶

以下示例以系统已部署验收、手动行驶已启用为前提。每条口令都等上一段播报结束再说。

```text
你：小车唤醒
车：已唤醒，请说指令

你：开启手动控制
车：手动控制已授权

你：前进速度零点一米每秒一秒
车：已接受运动请求
（观察实际运动，等动作结束）

你：后退一秒
车：已接受运动请求
（观察实际运动，等动作结束）

你：停车
车：已停车，控制授权已撤销
（确认小车已经停住）

你：退出语音
车：已退出语音会话
```

如果中途超过普通会话窗口，先重新唤醒。要继续行驶，普通停车后重新授权；急停后按第 4 节先复位再授权。

### 9.2 舌苔检测

以下示例以模块、相机和服务器已启用并完成现场检查为前提。结果中的特征仅用于说明播报形式，不是本轮真实检测结果。每条普通口令等上一段播报结束再说。

```text
你：小车唤醒
车：已唤醒，请说指令

你：舌苔检测
车：已进入舌苔检测模式。请正对相机，伸出舌头，保持不动。
（提示结束后留约两秒准备；程序自动获取新图并提交判断）
车：本次识别到黄苔、厚苔。可以说重新拍摄、播报上次结果，或退出舌苔检测。

你：播报检测结果
（小车重播本会话的结果，不重新上传）

你：重新拍照
车：请正对相机，伸出舌头，保持不动。
（程序重新拍摄、判断并播报新结果）

你：退出舌苔检测
车：已退出执行模式，小车保持停车。
（检测模式结束，车辆仍未授权）

你：退出语音
车：已退出语音会话
```

检测等待中需要取消时，普通会话仍有效且没有播报就直接说“退出舌苔检测”；已经超时则先说“小车唤醒”。紧急情况使用第 4 节的独立急停词和现场硬件停机方式。

调试人员的语音部署、模型、默认开关和实车验收步骤见[语音优化无车实施与验收](语音优化无车实施与验收.md)。舌苔模块启用开关 `WITH_TONGUE_MODE=true`、服务器配置、无车验证及现场待验收项见[语音舌苔流程整合与验收](语音舌苔流程整合与验收.md)。本说明书中的口令已按当前解析器和模式词表核对；这不等于真人语音识别率、车辆动作或舌象分类准确率已通过验收。
