# 小车语音控制使用说明书

版本：2026-10-04 · 适用于 `codex/fixed-voice-rules` 当前固定规则语音程序。

`codex/voice-tongue-integration` 保留本文驾驶口令并增加舌苔执行模式。启用该模块后，可用“小车唤醒 → 舌苔检测 → 重新拍摄 / 播报上次结果 / 退出舌苔检测”，完整前提和流程见[语音舌苔流程整合与验收](语音舌苔流程整合与验收.md)。在执行模式中明确“退出语音”“不用了”“休眠”会同时清理检测，普通 8 秒监听超时只暂停监听。

本说明书介绍当前代码支持的口令和使用方法。新程序尚未部署到小车，运动总开关、转向标定和微动标定默认关闭。以下行驶操作用于完成实车验收、由调试人员配置并启用相应功能之后；当前默认配置可以进行唤醒、查询和识别验证，不会因为说出行驶口令就开启运动。

## 1. 第一次使用：记住这个顺序

**系统就绪 → 小车唤醒 → 开启手动控制 → 等待授权成功 → 说一个动作 → 用完停车。**

先请调试人员确认程序、麦克风、扬声器和底盘已就绪，并说明哪些功能已验收启用。基础练习先使用直行；转弯、微动和人体跟随需要各自的实车条件满足后再使用。

| 操作 | 你说的话 | 接下来怎么做 |
|---|---|---|
| 唤醒 | **小车唤醒** | 等“已唤醒，请说指令”播报结束 |
| 请求手动授权 | **开启手动控制** | 等“手动控制已授权”；授权失败时先处理提示 |
| 短时前进 | **前进一秒** | 等动作完成和播报结束，再说下一条 |
| 短时后退 | **后退一秒** | 小车按本条指令的时长执行 |
| 普通停车 | **停车** | 确认小车停住；成功后手动/跟随授权都会撤销 |
| 结束交流 | **退出语音** | 结束普通指令会话；使用前先完成停车 |

“已接受运动请求”表示软件接收了指令，实际动作是否完成要观察小车。没有听到授权成功，或收到拒绝提示时，先查询状态，不继续发送行驶口令。

## 2. 怎么说，更容易被正确识别

- 面向麦克风，用正常音量清楚说话。实际可用距离需要现场测试，本说明书不承诺固定识别距离。
- 一次只说一个动作，例如“前进一秒”。说完稍停，当前程序以约 0.6 秒的静音判断一句话结束；整句话保持连贯，避免在动作与参数之间长时间停顿。
- 普通指令等小车播报结束再说。紧急停车词可以在播报期间喊出，独立急停通道仍在监听。
- 一次交互后，默认有约 8 秒可以继续说下一条普通指令。超过窗口，再说“小车唤醒”；说“不用了”“退出语音”或“休眠”可以结束会话。
- 重复唤醒会刷新会话。正在等待授权结果时先等结果，避免重新唤醒取消尚未完成的授权请求。
- 尽量使用下表中的直接口令。询问、否定、转述或一口气说多个动作，会被固定规则拒绝。

**8 秒是听下一条指令的窗口。** 每条行驶指令有自己的持续时间；跟随也不会因为会话过期而自动结束。需要停止运动时，应明确停车。

## 3. 常用口令速查

### 3.1 唤醒、授权和状态查询

| 想做什么 | 推荐口令 | 其他支持说法 | 说明 |
|---|---|---|---|
| 唤醒 | 小车唤醒 | — | 打开会话，保持原有已成功取得的运动许可；唤醒本身不授予许可 |
| 开启手动控制 | 开启手动控制 | 进入手动模式、切换到遥控模式 | 先停车切换模式，再检查并申请手动授权 |
| 开启跟随 | 开始跟随 | 开始跟随我、跟我走 | 需要有效的视觉目标及跟随条件，详见第 5 节 |
| 查询状态 | 查询状态 | 当前状态、小车现在是什么模式 | 报告模式、授权状态，以及当前有数据的电压/目标信息 |
| 查询电池信息 | 查询电量 | 电量多少、查询电池电压 | 当前有电压数据时报告伏特值，尚未提供可靠的电量百分比 |
| 查询目标 | 现在锁定了目标吗 | 是否在跟随、有没有锁定目标 | 返回当前状态信息，目标有效不等于已经获得运动授权 |
| 结束普通会话 | 退出语音 | 不用了、休眠 | 关闭普通指令会话，不是关机或停车口令 |

查询和模式口令应在普通会话中使用。一次切换模式会撤销旧许可并清除旧请求，需要等新的授权成功。

### 3.2 手动行驶

以下口令需要已经获得手动授权。

| 想做什么 | 推荐口令 | 效果及前提 |
|---|---|---|
| 前进 | 前进一秒 | 按配置速度向前行驶一秒 |
| 后退 | 后退一秒 | 按配置速度向后行驶一秒；也支持“倒车一秒” |
| 指定前进速度 | 前进速度零点一米每秒一秒 | 请求以 0.1 m/s 前进一秒 |
| 指定后退速度 | 后退速度零点一米每秒一秒 | 请求以 0.1 m/s 后退一秒，速度数值说正数即可 |
| 左转 | 左转一秒 | 向前走一段左弯曲线；需要转向参数已实车验收 |
| 右转 | 右转一秒 | 向前走一段右弯曲线；需要转向参数已实车验收 |
| 小幅前进 | 前进一下 | 微动；需要微动参数已实车验收 |
| 小幅后退 | 后退一下 | 微动；需要微动参数已实车验收 |
| 小幅转弯 | 左转一下、右转一下 | 分成两条独立口令使用；需要转向和微动均已验收 |

当前配置中，不说速度的普通直行请求默认使用 0.2 m/s，不说时长的普通动作默认持续 2 秒。软件允许直行速度大于 0、最高 0.2 m/s；单条动作时长为 0.05～2 秒。最终可用参数以实车验收配置为准，保护节点也可能拒绝或限制运动。

小车按阿克曼底盘处理，转弯会同时向前移动，不能原地旋转。口令中的转弯时长不代表转过指定角度，目前不支持“左转九十度”。

“一下”“一点”“稍微”会被当成微动要求。当前微动默认未启用，候选参数为 0.05 m/s、0.5 秒，实际位移尚未验证。基础练习使用“前进一秒”，待微动验收后再使用“前进一下”。

动作按时结束后，手动授权通常仍然保留，可以在会话内继续下一条；明确说“停车”则撤销授权，再次运动需重新开启手动控制。按时间执行不保证精确距离，目前不支持“前进一米”。

## 4. 停车、急停和恢复

### 普通停车

在普通会话中、播报结束后说 **“停车”**。成功后，小车停车并撤销当前手动或跟随授权。继续使用时，重新唤醒（会话过期时）、说“开启手动控制”或“开始跟随”，等待授权成功。

### 紧急停车

直接喊 **“停止”**。独立急停通道也监听 **“停下”“急停”“别动”**，设计上无需唤醒，在播报和会话外仍持续工作。

这四个词被独立通道检出后都会进入锁存急停，包括“停止”。因此喊“停止”后，可能需要复位才能继续行驶。独立通道检测关键词，不理解整句的否定或引用；车辆工作时，朗读或播放这些词也可能触发停车。

目前合成回放存在漏检：包括“急停”“别动”未检出，以及同一“停止”在不同流偏移下漏检。真人、运动噪声和播报双讲测试仍待完成，不能依赖语音作为唯一的停机方式。语音未生效时，应立即使用现场已确认的硬件停机方式；硬件停机装置的具体位置和方法由现场调试人员说明。

### 从锁存急停恢复

确认造成停车的情况已经处理、现场允许继续操作后，按顺序执行：

1. 说“小车唤醒”，等播报结束。
2. 说 **“解除紧急制动”**，等复位成功。
3. 说“查询状态”，确认当前未授权。
4. 说“开启手动控制”或“开始跟随”，等授权成功。
5. 再发送运动指令。

复位只解除锁存，车辆不会自动恢复原动作。使用准确口令“解除紧急制动”，避免说“解除急停”再次触发急停关键词。普通停车、模式切换和重启程序都不能解除急停锁存。

### 从故障停车恢复

音频断流、急停通道异常、请求或感知数据过期等情况，可能使已授权系统进入故障状态。先请调试人员排除原因，再唤醒并说 **“复位故障”**。收到复位成功后重新选择模式、取得授权。原因仍存在时，复位或授权会被拒绝；不能通过反复发口令绕过。

## 5. 怎么使用人体跟随

跟随功能要求视觉系统提供有效的已锁定目标，并完成测距、安装、底盘及保护参数的实车验收。

1. 请调试人员确认当前锁定的是准备跟随的人，可以在 Foxglove 或状态反馈中核对目标。
2. 说“小车唤醒”，等播报结束。
3. 说“查询状态”，确认目标和控制状态。
4. 说“开始跟随”，等“跟随控制已授权”。授权成功且目标有效后，小车可能立即开始跟随，无需再说“前进”。
5. 要结束跟随，在普通会话内说“停车”；紧急情况直接喊急停词。

“跟随我”“跟我走”是开启跟随的口令，车辆跟随的是视觉系统当前锁定的目标。当前没有通过声纹识别说话者，也没有用说话方向自动选中对应的人。

目标丢失或数据失效时，跟随请求会变为零，保护节点可能进入故障。目标重新出现不代表自动恢复许可；先查询状态，再按提示处理。要改用方向口令，先说“开启手动控制”并等授权成功。

## 6. 常见问题

| 现象 | 可能原因和处理方法 |
|---|---|
| 唤醒了，但小车不动 | 唤醒没有授予运动许可；当前源码默认关闭运动，需先由调试人员完成配置和验收 |
| 提示“请先完成手动模式授权” | 当前未授权或处于跟随模式；开启手动控制并等成功反馈 |
| 提示“授权等待超时”或控制服务不可用 | 必要节点、状态或零请求尚未就绪；交给调试人员检查后重新发起授权 |
| 前进能用，左转或“一下”被拒绝 | 对应转向/微动标定未启用；先使用已验收的普通直行口令 |
| 播报时说普通指令没反应 | 普通识别会丢弃播报期间的结果；等播报结束再说，紧急情况使用独立急停词 |
| 一段时间后普通口令没反应 | 约 8 秒的会话窗口可能已过；重新说“小车唤醒” |
| 停车后再说“前进”被拒绝 | 停车撤销了授权；若是急停锁存，先复位，再重新授权 |
| “电量”没有百分比或没有电压 | 目前只在收到电压数据时播报伏特值；缺数据时不会编造电量 |
| 提示语句不明确 | 一次只说一个直接动作，去掉询问、否定、转述和多个动作 |
| 收到“已接受运动请求”，却没有实际移动 | 该反馈仅表示适配节点接收了请求；最终保护或硬件仍可能阻止运动，请查询状态并让调试人员检查 |

## 7. 当前不支持的用法

| 说法 | 为什么不执行 | 可用替代 |
|---|---|---|
| 能不能前进？ | 属于询问 | 前进一秒 |
| 不要前进、他说前进 | 属于否定或转述 | 有意行驶时直接说单一动作 |
| 先前进，再左转 | 同一句包含多个动作 | 分别发两条指令，逐条等待反馈 |
| 前进一米 | 尚未接入里程计距离闭环 | 前进一秒；实际距离需观察 |
| 左转九十度、原地左转 | 未提供角度控制，阿克曼底盘不能原地旋转 | 已验收后使用左转一秒 |
| 去客厅、去充电点 | 语音入口尚未接入地点映射和导航目标 | 当前没有对应语音替代功能 |
| 退出语音后就自动停车 | 会话结束只关闭普通监听 | 先“停车”并确认停住，再“退出语音” |

## 8. 完整使用示例

以下示例以系统已部署验收、手动行驶已启用为前提。每条口令都等上一段播报结束再说。

```text
你：小车唤醒
车：已唤醒，请说指令

你：开启手动控制
车：手动控制已授权

你：前进速度零点一米每秒一秒
车：已接受运动请求
（观察实际运动，等动作结束）

你：后退一秒
车：已接受运动请求
（观察实际运动，等动作结束）

你：停车
车：已停车，控制授权已撤销
（确认小车已经停住）

你：退出语音
车：已退出语音会话
```

如果中途超过普通会话窗口，先重新唤醒。要继续行驶，普通停车后重新授权；急停后按第 4 节先复位再授权。

调试人员的部署、模型、默认开关和实车验收步骤见[语音优化无车实施与验收](语音优化无车实施与验收.md)。本说明书中的口令已按当前固定解析器核对；这不等于真人语音识别率或车辆动作已通过验收。
