# 固定语音规则与离线验收

更新日期：2026-10-04。分支：`codex/fixed-voice-rules`，从 `main` 的 `59847c0` 创建。按用户要求停止 Jev 模型试验，没有合并模型实验代码；旧分支保留历史。本轮仅修改本机代码，没有连接、部署或启动小车。

## 识别范围

本次优化的是 ASR 文本到动作的固定规则。正式默认 ASR 为本地 Qwen3-ASR 0.6B INT8，随后经过 `voice_command_router` 和本地 TTS。规则不调用 Ollama、不依赖模型推理。麦克风收音、声学识别、唤醒和 ROS 控制授权逻辑不在本次改动范围内。

| 意图 | 支持的说法示例 | 解析结果 |
| --- | --- | --- |
| 前进 | 向前挪一下、往前走一点、小车朝前开动 | `DRIVE`，线速度为正 |
| 后退 | 往后挪一下、向后倒一点、朝后开动 | `DRIVE`，线速度为负 |
| 左转 | 往左转一下、朝左边转动、向左调整方向 | `DRIVE`，角速度为正 |
| 右转 | 往右拐、朝右侧转动、向右调整方向 | `DRIVE`，角速度为负 |
| 手动授权 | 请开启手动驾驶模式、切换为手动模式、启动遥控授权 | `ARM` |
| 跟随 | 跟着我走、跟我走、切换到人体跟随模式 | `SET_MODE: FOLLOW` |
| 停止 | 停住小车、马上停下来、先别动了、取消跟随、退出手动模式 | `STOP` |
| 查询 | 报告一下剩余电量、告诉我现在的控制模式、有没有锁定目标 | `QUERY_STATUS: status` |

句首允许组合“小车、请、请你、帮我、麻烦、麻烦你、现在、马上、立即、先”，例如“小车，请帮我现在向前挪一下”。完整匹配后才产生动作，不从长句中抽取方向词。原有同一方向词的整句重复（例如“前进前进”）仍按一个动作处理；不同动作连说会拒绝。

## 参数表达

方向后可接速度和持续时间，两者可交换顺序。支持阿拉伯数字、全角数字、中文数字、中文小数及“半秒”“两秒钟”。例如：

| 说法 | 线速度 m/s | 角速度 rad/s | 持续时间 s |
| --- | ---: | ---: | ---: |
| 前进零点一米每秒半秒 | 0.1 | 0 | 0.5 |
| 倒车每秒零点二米两秒钟 | -0.2 | 0 | 2 |
| 左转角速度零点五弧度每秒零点零五秒 | 0 | 0.5 | 0.05 |
| 朝右边转一秒速度0.4 | 0 | -0.4 | 1 |

没有明确数字时继续读取运行配置。当前离线配置默认前进 `0.2 m/s`、后退 `-0.2 m/s`、转向 `±0.25 rad/s`、持续 `2 s`；纯函数测试使用原有默认 `±0.08 m/s`。本次没有改变这些默认值或限速。

“一下、一点、短暂”属于口语表达，仍采用配置中的持续时间，不换算为距离或更短时间。需要短动作时请说“前进半秒”等明确时间。

线速度范围保持 `-0.2..0.2 m/s`，角速度绝对值不超过 `0.5 rad/s`，时间保持 `0.05..2 s`。单说“速度”使用当前方向对应单位；明确单位必须正确：直行接受米每秒，转向接受弧度每秒。错误单位、重复参数、负数、零运动、越界值或不完整数字均拒绝，不截断、不猜测。

## 拒绝规则

- 否定、能力询问、引用、假设或将来条件不触发动作，例如“不要前进”“你能前进吗”“他说前进”“明天再左转”。“不要动”“别动了”是明确停止指令。
- 一句话只执行一个动作。“前进然后后退”“停止，前进”“进入手动再往后走”均拒绝，先说“开始遥控”，获得授权回复后再说方向。
- 保留问号和引号的含义；明确状态询问可返回状态，运动询问会拒绝。
- “前景”“又赚”等相近读音不自动改写为运动命令。
- 距离、角度、绕障、鸣笛、车灯、送物和坐标目标没有新增执行能力。少量明确地点请求返回原有“导航未接入”提示，其余返回未识别或参数拒绝提示。

路由器仍通过既有模式服务授权，并经 `motion_guard` 请求速度。解析成功仅代表识别了指令，实际授权、超时与车辆保护由既有控制链路处理。

## 本机验证结果

复用前期人工编写的 240 条文本作为固定回归集，20 类、每类 12 条，涵盖支持指令和非执行输入。所有文本均已可见；JSONL 中保留的 `dev/test` 标签只是历史元数据，本次没有将其当成独立盲测。没有使用真实录音，结果不能代表真人语音识别成功率或泛化准确率。

| 指标 | 原规则（59847c0） | 本分支规则 |
| --- | ---: | ---: |
| 支持指令命中（含状态查询） | 48/96（50%） | 96/96（100%） |
| 停止指令命中 | 6/12 | 12/12 |
| 非执行输入触发动作 | 0/144 | 0/144 |
| 全部分类标签一致 | 177/240（73.75%） | 231/240（96.25%） |

剩余 9 条分类差异均为未支持功能：回归标签为 `UNSUPPORTED`，规则拒绝后记为 `NONE`，没有执行动作。完整报告由下方命令生成，包含基线提交、数据及解析器 SHA-256、分类统计和未命中明细。

纯逻辑回归 **1546 项通过**，覆盖这 240 条文本、明确参数值、配置默认值、936 个否定/疑问/引用等变体、280 个双动作组合及数值边界。1 个 ROS 路由测试因本机缺少 `rclpy` 跳过。尚未进行 ROS 构建、Jetson 部署、麦克风或实车测试。

在仓库根目录执行：

```bash
PYTHONPATH=ros2_ws/src/voice_command_router python3 -m pytest -q ros2_ws/src/voice_command_router/test
python3 scripts/benchmark_voice_rules.py --output artifacts/fixed-voice/report.json
```

脚本只读取 Git 中的旧解析器与文本集，不导入 ROS、不连接服务器。后续可用 `--cases` 指定相同 JSONL 格式的真实 ASR 文本（字段至少包含 `id`、`utterance`、`expected`、`category`），用同样的规则比较方法核对。

回学校后先单独录制本人指令和环境噪声，并保留原始 ASR 文本，分别计算“语音转写正确率”“文本到意图命中率”和“控制链路执行成功率”。先验证静止状态下的查询和拒绝行为，再在现场验证授权与短动作。
