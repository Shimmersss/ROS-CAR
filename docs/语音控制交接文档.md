# 语音 ROS 控制交接文档

更新时间：2026-09-28

## 1. 本次交付范围

语音链路已经从“问答加蜂鸣器工具”改为受保护的 ROS 控制编排层：

```text
麦克风/讯飞 ASR
        │ /voice/asr_text
        ▼
voice_command_router ──本地中文规则──► 控制服务与 /chassis/cmd_vel
        │
        └─无法确定的文本──► /voice/unhandled_text
                                  │
                                  ▼
                         deepseek_chat（单工具结构化调用）
                                  │ /voice/command
                                  ▼
                         voice_command_router

/chassis/cmd_vel ──► motion_guard ──► /cmd_vel ──► 底盘
```

路由器不直接发布最终 `/cmd_vel`，也不会因为节点启动而自动 arm。当前这一版本完全取消雷达参与：不启动 N10P/雷达，`motion_guard` 固定使用 `radar_required:=false`，任何模式切换、授权和语音控制均不得等待 `/scan`、雷达 TF 或雷达净空结果。运动仍受模式、速度、请求超时和底盘自身停车保护约束。

## 2. 类型化接口

`roscar_interfaces` 新增：

- `roscar_interfaces/msg/VoiceCommand`：`request_id`、`action`、`mode`、`linear_mps`、`angular_rps`、`duration_s`、`query`、`stamp`。
- `roscar_interfaces/msg/VoiceCommandResult`：请求 ID、成功标记、动作、播报文本、当前控制模式、保护状态和时间戳。

动作白名单为 `DRIVE`、`SET_MODE`、`ARM`、`STOP`、`DISARM`、`QUERY_STATUS`、`BUZZ`。旧 `/voice/tool_call` 的蜂鸣器 JSON 入口仍保留，便于兼容旧客户端。

关键 ROS 话题和服务：

| 用途 | 接口 |
| --- | --- |
| ASR 输入 | `/voice/asr_text` (`std_msgs/String`) |
| DeepSeek 兜底输入 | `/voice/unhandled_text` (`std_msgs/String`) |
| 结构化命令 | `/voice/command` (`VoiceCommand`) |
| 结构化结果 | `/voice/command_result` (`VoiceCommandResult`) |
| 外部速度请求 | `/chassis/cmd_vel` (`geometry_msgs/TwistStamped`) |
| 控制模式 | `/control/set_mode` (`roscar_interfaces/SetControlMode`) |
| 授权/停止 | `/control/arm`、`/control/stop`、`/control/disarm` (`std_srvs/Trigger`) |
| 状态输入 | `/control/state`、`/PowerVoltage`、`/odom`、`/perception/target_state` |

## 3. 已支持的中文命令

- `开始遥控`、`手动驾驶`：请求 `EXTERNAL`，等待新鲜状态后显式 arm。
- `开始跟随`：请求 `FOLLOW`；没有真实有效目标时由 guard 拒绝授权。
- `停止`、`急停`、`退出遥控`、`不要动`：零速度、stop/disarm，并回到 `IDLE`。
- `前进`、`后退`、`左转`、`右转`：仅在已授权 `EXTERNAL` 下执行。
- 可带明确数值，例如 `后退 0.1 米每秒 1 秒`、`右转速度 0.4 两秒`。
- `电量`、`当前状态`、`是否在跟随`：读取实时状态后播报。
- 包含 `导航`、`去客厅` 等地点目标：明确回复当前未接入导航目标，不产生运动。

默认参数：前进 `0.08 m/s`、后退 `-0.08 m/s`、转向 `±0.25 rad/s`、单次最多 `2 s`。速度、角速度、时间都经过有限数值和范围校验；线速度范围为 `-0.15..0.15 m/s`，角速度绝对值不超过 `0.5 rad/s`。

## 4. 安全行为

- 语音控制使用一次显式授权会话；启动节点不会自动 arm。
- 没有新的运动指令达到 2 秒时，路由器发布零速度并调用停止，撤销本轮授权。
- 控制模式切换后，路由器等待新鲜 `/control/state`，确认模式和 `ready` 后才调用 arm。
- 路由器退出时不刷新运动请求；`motion_guard` 的请求看门狗继续负责停车。
- 非 `EXTERNAL` 模式不发送有效手动速度；`FOLLOW` 不复用手动速度通道。
- `motion_guard` 的 `max_reverse_mps` 默认是 `0.15`，允许语音手动模式有限倒车；跟随和导航生产者仍可保持不倒车。

## 5. 配置和启动

主要配置文件：

- `ros2_ws/src/xfyun_speech/config/voice_assistant.yaml`
- `ros2_ws/src/xfyun_speech/launch/voice_assistant.launch.py`
- `ros2_ws/src/motion_guard/config/safety.yaml`

语音启动文件增加 `voice_control_enabled:=true|false`。关闭时仍可保留普通问答链路，但不执行控制动作。启动前应确认已启动 `motion_guard`、其模式服务和底盘驱动；语音模块本身不负责打开底盘。

建议现场顺序：

1. 启动底盘和 `motion_guard`（固定 `radar_required:=false`），确认 `/cmd_vel` 只有 guard 发布者；本版本不要启动雷达节点，也不要配置雷达 TF、扫描超时或雷达净空检查。
2. 启动讯飞 ASR、`voice_command_router` 和 `deepseek_chat`；需要播报时再启动 TTS。
3. 先说“当前状态”，确认状态链路正常。
4. 说“开始遥控”，确认进入 `EXTERNAL` 和 `ARMED`。
5. 只在空旷环境测试短促“前进”“后退”，最后说“停止”。

## 6. DeepSeek 兜底约束

DeepSeek 只订阅 `/voice/unhandled_text`，本地已识别命令不会重复送云端。允许的工具为 `drive`、`set_control_mode`、`arm`、`stop`、`query_status`、`buzz`，每次最多一个工具调用，参数使用固定 JSON Schema 并拒绝未知字段。工具调用发布 `VoiceCommand`，必须等待 `VoiceCommandResult`；ROS 返回失败或超时会转为失败播报，模型不得自行声称动作完成。

## 8. 尚未完成的现场工作

- 未在 Jetson 上部署或进行真实语音驾驶验收。
- 未执行倒车实车动作；必须先确认车轮方向、场地和急停可用。
- 未接入 Nav2 目的地语义，地点命令仍只返回未接入提示。
- 蜂鸣器硬件路径仍是兼容入口，具体下位机蜂鸣反馈需单独验收。
- 需要现场检查重复发布者、`/control/state` 新鲜度、`motion_guard` 的几何/停车确认参数，以及 `/cmd_vel` 最终发布者。当前版本明确不做雷达避障验收，雷达不是任何控制门禁；后续若重新启用雷达，另行变更版本和验收范围。
