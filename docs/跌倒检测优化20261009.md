# 跌倒检测优化（2026-10-09 补录首轮）

> 结论性质：**单场次、未标注、目测计数**的初步结果。阈值在同一批录像上调过，存在过拟合；录像与补录安排有多处偏差（见 §2）。所有新开关默认关闭，正式默认值须在标注后用 `scripts/evaluate_falls.py` 复评再定。不是板端或实车验收。

## 1. 数据与工具

- 录像：`data/recordings/gemini-20261009-*`（A1a、A1b-part2、A1c、A2a、A4a、A5），Mac 录制，主机时间配对，非曝光同步。
- Pose 缓存：`artifacts/fall-eval-20261009/poses/<段>/frames.jsonl`（YOLO26s-pose，每 2 帧推理一次）。
- `scripts/replay_falls.py`：按录像时间重放跌倒规则，模式 `2d` / `3d-fixed` / `3d-floor` / `height`，`--variant` 组合新开关（`gap_pause`、`knee_fallback`、`handover=<s>`、`transition=<s>`、`confirm_lying_only`、`veto2d`）；缓存地面拟合 `floor.jsonl` 与身体高度 `heights.jsonl`；输出 `timeline-*.jsonl`、`report.json`、`timeline.png`，相隔 ≤1.5 s 的同类阶段合并为一次事件。
- `scripts/evaluate_falls.py --pair 录像 重放目录 --output 输出`：读取 `labels.csv`，给出每次跌倒是否疑似/确认、相对触垫时刻的延迟、反例动作误报和标注外检出。**本轮录像尚无标注，未能运行。**

## 2. 录像偏差

- 段内容与段名不符：A1b-part2 实为侧向跌倒，A1c 实为朝相机跌倒，A1a 为混合。
- 躺地时间仅 1–2 s（要求约 4 s），确认阶段需 1 s 持续证据，余量很小。
- 看护人常在画面内并遮挡；A1a、A1c 段中途移动了相机（固定重力失效）；垫子偏薄；`notes.md` 未填写相机高度/俯仰/横滚。
- 彩色偏蓝为白平衡问题（已核对非通道互换），对检测影响未量化。

## 3. 漏检根因（逐帧查看时间线）

1. **低机位遮挡**：头朝相机俯卧时肩/髋被遮，二维规则报“关键点不足”或“躯干倒置”；远处正面俯卧被判 STANDING。
2. **躺卧低置信**：躺卧检测置信度 0.1–0.3，ByteTrack 不建轨或断轨，跌倒前后轨迹号不同，丢失直立基线。
3. **无直立基线**：看护人遮挡、他人入画、关键点贴边。
4. **跌倒耗时**：受试者从开始到触垫约 1.6 s，超过 `transition_s=1`。
5. **确认阶段复检下坠**：躺地后的小幅移动即取消疑似。
6. **缺帧重置**：UNKNOWN 帧打断确认/恢复计时。
7. **地面拟合不可靠**：反光瓷砖、垫面形成第二平面；有效帧约 37%，稳定帧仅 5–35%（各段 `floor.stable_fraction`）。

## 4. 新增开关（全部默认关闭）

| 参数 | 作用 |
|---|---|
| `pose_gap_pause` | 几何缺失 ≤`max_gap_s` 时暂停（而非清零）计时，恢复后平移计时 |
| `pose_handover_s` | 0–3 s；一条轨迹消失时，若唯一一条新轨迹出现在其下方附近，则继承其状态与计时（应对躺卧断轨） |
| `pose_confirm_lying_only` | 疑似后只要求“仍躺卧”，不再复检下坠幅度 |
| `pose3d_knee_fallback` | 膝缺失但躯干直立时用二维 STANDING/SITTING 判定，不再报几何不足 |
| `height_fall_enabled` | 无骨架的身体顶高度线索：框内最近深度簇沿重力的 95 分位高度，直立 ≥0.8 m → 躺地 ≤0.55 m，下降 ≥0.4 m、2 s 内完成、持续 1 s 确认；骨架明确直立/坐蹲时视为下蹲并取消；未测帧暂停计时。仅当重力与地面均已确认才可升为确认，否则最多疑似 |

`pose.yaml` 中以注释列出，`height_upright_min_m` / `height_low_max_m` / `height_drop_min_m` / `height_transition_s` 同时暴露。`height_fall` 结果写入 `PersonPose.detail`（`height_fall=N (...)`），不改变 `TargetState`，不接语音或运动。

## 5. 目测结果（S=疑似事件，C=确认事件）

| 段 | 实际跌倒（目测） | 原规则（2d / 3d-fixed） | 最佳骨架组合 | 高度 + handover 1.5 | 高度 + handover + 骨架否决 |
|---|---|---|---|---|---|
| A1a | 约 4 | S0 C0 | S0 C0 | S4 C3 | S3 C1 |
| A1b-part2 | 约 8 | S1 C0 | S2 C2（gap_pause+knee+handover+transition 2+confirm_lying_only） | S7 C7 | S7 C6 |
| A1c | 约 5 | S1 C0 | S1 C0 | S5 C3 | S5 C3 |
| A2a | 未定 | S0 C0 | S1 C0 | S1 C0 | S1 C0 |
| A4a（快速反例） | 0 | S0 C0 | S0 C0 | S0 C0 | S0 C0 |
| A5（日常姿态） | 0 | S0 C0 | S0 C0 | S4 C2（深蹲） | S2 C0 |

- 骨架规则开关只带来小幅改善：根因 1、2 让多数跌倒在骨架层面根本不可见。
- 高度线索是唯一明显提升检出的方法，但无否决时深蹲误报；加骨架否决后 A5 确认误报消失、仍有 2 次疑似。
- 高度依赖本段地面拟合给出的相机高度/重力（A1b 拟合约 0.75 m、抬头 −11.5°、横滚 −2.9°，稳定帧仅 5%），实测高度偏差约 0.3–0.5 m；深度竖直视场只有 45.3°，站立顶高被截在约 1.0 m。阈值因此偏低，换场地或实测安装参数后必须重调。
- 水平伸展（`body_heights(..., extent=True)`）能区分侧躺（0.77–1.09 m）与下蹲（0.40–0.53 m），但区分不了正面俯卧（约 0.5 m），本轮未接入规则。
