# 5060 推理服务启停说明

适用于 5060 笔记本的 WSL（Ubuntu，root 用户）。这台机器为小车提供拍照推理，入口命令是 **`roscar-infer`**。

- 脚本源码：`services/inference_gateway/deploy/roscar-infer`
- 安装位置：`/root/roscar-models/bin/roscar-infer`，并软链接到 `/usr/local/bin/roscar-infer`

## 1. 管着哪些东西

| 组件 | 作用 | 监听 / 去向 | 日志 |
|---|---|---|---|
| `tongue` | 舌象原包 HTTP 服务（分割模型 + 10 个分类模型，GPU） | `127.0.0.1:8096`，只给网关用 | `/root/roscar-models/logs/tongue.log` |
| `gateway` | 统一推理网关，含 PCB、安全帽 YOLO（GPU），并代理舌象服务；需要 Bearer token | `127.0.0.1:8200` | `logs/gateway.log` |
| `tunnel` | 从 WSL 发起的受限 SSH 反向隧道 | 小车 `127.0.0.1:18200` → WSL `127.0.0.1:8200` | `logs/tunnel.log` |

小车上的 `roscar-capture-inference.service` 通过 `inference_url=http://127.0.0.1:18200` 访问网关。face 没有模型，固定返回 `model_unavailable`。

每个组件都跑在自己的"守护循环"里，各有独立的进程组和 pid 文件（`/root/roscar-models/run/*.pid`）。进程崩溃 5 秒后自动重启，隧道断线 10 秒后自动重连。网关每次启动前会先等舌象服务就绪（最长 600 秒）；否则网关会把舌象标记为不可用，直到下一次重启网关。

## 2. 常用命令

```bash
roscar-infer status            # 三个组件、端口、网关健康状态（各模型 ready/device、GPU 剩余显存）、隧道最近日志
roscar-infer start             # 启动全部；已在运行的组件会跳过
roscar-infer stop              # 停止全部（顺序：tunnel → gateway → tongue）
roscar-infer restart           # 重启全部
roscar-infer restart gateway   # 只重启某个组件：tongue | gateway | tunnel
roscar-infer logs gateway -f   # 跟踪日志；不加 -f 时只显示最后 50 行
roscar-infer test              # 用合成图对四个任务各请求一次（只验证链路）
```

`test` 的预期结果：pcb 和 helmet 为 `ok`，并且 `image_sha_ok=True`；tongue 为 `retake`（合成图里没有舌头）；face 为 `model_unavailable`。

**改了网关代码或配置之后：**

```bash
roscar-infer restart gateway
```

**改了舌象服务的参数之后：**

```bash
roscar-infer restart tongue gateway
```

舌象重启后，网关也需要重新检查舌象的版本信息。

## 3. 开机自动启动（已配置）

1. **WSL 启动时**：`/etc/wsl.conf` 的 `[boot]` 段执行
   ```
   command=service ssh start; /root/roscar-models/bin/roscar-infer boot
   ```
   原文件已备份为 `/etc/wsl.conf.bak-roscar-infer.<时间>`。
2. **Windows 登录时**：当前用户的计划任务 **`ROSCAR WSL inference`** 运行
   ```
   conhost.exe --headless wsl.exe -d Ubuntu -u root -- roscar-infer keepalive
   ```
   它会启动全部组件，然后保持一个隐藏的 WSL 客户端常驻，防止 WSL 空闲时退出。不会弹出窗口。

要取消开机自启：

```bash
roscar-infer uninstall-windows-autostart   # 删除 Windows 计划任务
roscar-infer uninstall-boot                # 从 /etc/wsl.conf 移除开机命令（会先备份）
```

要恢复开机自启，执行对应的 `install-windows-autostart` / `install-boot`。

注意事项：

- 只有**登录 Windows 之后**才会自动启动。笔记本合盖睡眠时 WSL 会暂停，唤醒后隧道会自动重连。
- 执行 `wsl --shutdown` 会停掉全部服务；之后打开任意 WSL 窗口，或手动运行计划任务，就会自动恢复。

## 4. 配置

脚本默认值对应当前部署。要修改的话，新建 `/root/roscar-models/roscar-infer.env`（shell 变量格式），只写需要改的项：

```bash
ROBOT=wheeltec@192.168.31.145     # 小车地址变了就改这里
REMOTE_PORT=18200                 # 小车端监听端口，必须与车端 inference_url 和 authorized_keys 的 permitlisten 一致
TUNNEL_ENABLED=true               # 小车改为直连 8200 时设为 false
GATEWAY_CONFIG=/root/roscar-models/gpu-20261016/gateway.private.yaml
GATEWAY_TOKEN=/root/roscar-models/gpu-20261016/gateway.token   # 必须是 0600 权限，与小车 ~/.config/roscar/gateway.token 内容相同
```

小车地址变化后，还要更新 `onboard-link/known_hosts`。最简单的方法：用 `ssh-keyscan <新地址>` 获取主机公钥，核对指纹无误后再写入。

隧道使用的密钥是 `onboard-link/id_ed25519`。小车 `authorized_keys` 里对它的限制是：只能在 `127.0.0.1:18200` 上建立反向转发，`command=/bin/false`，不能登录 shell。

## 5. 确认小车能用

在小车上执行：

```bash
curl --noproxy '*' -s -H "Authorization: Bearer $(cat ~/.config/roscar/gateway.token)" \
  http://127.0.0.1:18200/health/ready
```

返回 `"status": "ready"`，并且 tongue、helmet、pcb 都是 `ready: true`，就说明隧道和网关都正常。

如果要做端到端测试，在小车上调用 `/inspect/<任务>`：小车会播报并拍照，详见 `docs/ROS接口使用文档.md`。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| `status` 显示某个组件 stopped | 执行 `roscar-infer start <组件>`，再用 `logs <组件>` 看退出原因 |
| `start` 提示端口被未托管进程占用 | 有人手动起了旧进程。先执行 `roscar-infer stop-legacy --dry-run` 查看会停哪些进程（只精确匹配本服务的旧命令行），确认无误后再执行 `stop-legacy` 和 `start` |
| 健康检查中 tongue 显示 unavailable | 舌象服务比网关晚就绪。执行 `roscar-infer restart gateway` |
| **隧道端口被占用**：`tunnel.log` 反复出现 `remote port forwarding failed for listen port 18200` | WSL 异常断网后，小车的 sshd 没发现旧连接已经断开，旧会话一直占着 18200。不处理的话，大约 2 小时后小车的 TCP 保活才会把它清掉。处理方法见下方说明 |
| 网关报 OOM，或显存不足 | 用 `status` 查看 GPU 剩余显存。Windows 本身大约占 2 GB；关掉其他 GPU 程序后执行 `restart` |

**隧道端口被占用时的处理：**

- **长期方案（推荐，需要小车 sudo，做一次即可）**：在小车上执行
  ```bash
  printf 'ClientAliveInterval 15\nClientAliveCountMax 3\n' | sudo tee /etc/ssh/sshd_config.d/roscar-alive.conf
  sudo systemctl reload ssh
  ```
  之后旧会话在约 45 秒内就会被清掉，隧道会自动重新绑定。
- **临时方案**：在小车上找到那个旧的隧道会话，只结束它一个。千万不要按用户名批量结束进程，那会把小车主服务一起杀掉。最简单可靠的办法是重启小车。

## 7. 版本与限制

- 网关代码来自仓库 `services/inference_gateway/` 的副本，位于 `/root/roscar-models/gateway-source/`。更新时，把仓库中的该目录覆盖过去，然后执行 `roscar-infer restart gateway`。
- 舌象在 GPU 上使用 torch 2.8 + cu128，与原包 torch 2.4 CPU 版的最大分数差为 0.008，超过原定的 0.001 门槛。用户已明确允许直接使用 GPU。分数接近阈值的标签，判定可能与原版不同。
- 只验证过链路能走通，真人、实物的识别准确率还没有验收。
