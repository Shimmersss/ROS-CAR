# N10P 雷达 ROS 接入

用户确认实物型号 N10P。项目使用已迁入的雷神 ROS 2 驱动，配置名 `N10Plus`，串口 460800、默认 10 Hz。官方驱动入口也列出 [M10P/N10P](https://github.com/Lslidar/Lslidar_ROS2_driver)，仓库配置依据本地驱动的 N10Plus 解码实现；实物型号、数据格式的最终匹配以现场输出验收为准。

## 构建与启动

Linux ARM64 ROS 2 Humble，先安装依赖（Mac 使用下述 Docker 测试）：

```bash
sudo apt-get update
sudo apt-get install ros-humble-pcl-conversions libpcl-dev libpcap-dev libyaml-cpp-dev libboost-thread-dev
bash scripts/build_ros.sh
bash scripts/build_radar.sh
bash scripts/run_radar.sh serial_port:=/dev/wheeltec_lidar
```

`build_radar.sh` 在独立 radar_src 副本中编译 `lslidar_msgs` 和 `lslidar_driver`，安装至 `ros2_ws/radar_install`。其他厂商雷达包继续忽略；不会同时打开多个驱动。原始目录的 COLCON_IGNORE 保留。

`/dev/wheeltec_lidar` 是待现场检查的默认别名，不代表已经确认端口。可传入实际 `/dev/serial/by-id/...`。不执行厂商 udev 脚本，避免把相同 USB 转串口芯片的底盘端口误绑到雷达。

与现有感知组合：

```bash
source /opt/ros/humble/setup.bash
source ros2_ws/radar_install/setup.bash
source ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=182
ros2 launch perception_bringup perception.launch.py route:=astra with_radar:=true
```

这里 astra 仍仅启动已有适配器，原始相机/骨架数据源按原流程运行；如果 A 服务已经在运行，直接单独启动 run_radar.sh，避免重复启动 A。B/red 同样可加 `with_radar:=true`，原感知参数照常传入。with_radar 默认 false，现有启动不受影响。

## 话题与坐标

| 话题 | 类型 | 用途 |
|---|---|---|
| `/scan` | sensor_msgs/LaserScan | 原生二维扫描 |
| `/radar/points` | sensor_msgs/PointCloud2 | 同坐标系点云 |
| `/radar/status` | std_msgs/String（JSON） | WAITING/OK/NO_RETURNS/INVALID/STALE、频率、有效点数、最近回波 |

默认 frame 为 `laser`。Foxglove 3D 面板选择 `laser` 为固定坐标系，并开启 `/scan` 或 `/radar/points`；原始消息面板查看 `/radar/status`。已有 Foxglove Bridge 可自动发现这些话题，需与雷达在同一 ROS_DOMAIN_ID。

`config/radar.yaml` 保存串口/网络、话题和安装参数。默认不发布任何安装 TF；测量 `base_link → laser` 的平移和旋转后，填写 translation/rotation_rpy（米/弧度），同时设置 mount_calibrated 与 publish_mount_tf 为 true。已有 URDF/TF 提供安装变换时保持 false，避免重复发布。

驱动原实现对 LaserScan 的 Y 取反，却不对同 frame 的点云取反；本地补丁将扫描方向统一为 atan2(y,x)。修复保持扫描与点云一致，仍需现场验证雷达物理正前方及安装朝向。原始哈希保留，补丁清单单独记录。

状态监测仅描述数据质量，不代表通道可通行。有效量程暂取 0.15–15 m；盲区、空回波、时间戳异常都不能等同于没有障碍。当前不把最近回波接入 `/cmd_vel`，不启用避障或车辆运动。

## 本机验证与现场验收

```bash
bash scripts/test_radar_container.sh
```

测试构建实际雷神驱动，并在伪串口中输入 N10Plus 108 字节合成数据，检验真实驱动输出 `/scan`、点云、1 m 左侧/2 m 其余方位及坐标方向；另外验证状态监测、陈旧/空回波、TF 确认条件和既有路由。合成数据不是实机测量。

现场还需核对设备别名、无重复驱动、实测帧率和障碍距离、正前/左/右方向、安装 TF，以及拔线后 STALE。本轮本机接入不代表已部署 Jetson 或通过这些实机验收。
