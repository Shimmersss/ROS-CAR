# 当前语音入口与回退

2026-10-12：远端 C/Gemini 更新与本地语音合并后的源码入口。未在本轮部署到小车。

## 怎么用

说“小微小微”，等“已唤醒，请说指令”播完再说“查询状态”等口令。每次成功交互后有 8 秒续聊窗口，再次唤醒刷新窗口。未匹配或含糊指令按本地原逻辑播报提示，控制门禁拒绝时播报原因。

运动能力默认关闭。启用能力和完成现场校准后，也必须先“开始遥控”等显式授权；方向口令不会自动授权。STOP 撤销运动授权，急停持久锁存，复位只回到未授权状态。详细口令与边界见 [语音控制说明书](语音控制使用说明书.md)。

开启舌苔模式后，说“舌苔检测”，先停车并取得任务保持，再播报准备提示、等待两秒、获取新鲜原始 RGB、上传冻结版本服务并播报结果。保持期间禁止运动授权；退出不会恢复运动。见 [舌苔整合与验收](语音舌苔流程整合与验收.md)。

## 收音与执行链路

唯一 `audio_node` 以 16 kHz 单声道 PCM16 / 40 ms 帧发布 `/voice/audio`；常开 KWS 与 ASR 共享该音频。TTS 期间继续采集和急停识别，只抑制普通 ASR。Qwen3-ASR / Silero VAD 分句识别后，固定规则输出语义请求，由阿克曼能力适配器和唯一 motion_guard 检查；不使用大模型生成运动。

唯一 MeloTTS 提供有播放完成确认的 `/voice/speak`。专用语音舌苔试运行启用 `/voice/say` 服务；组合入口需要时独立启动桥接，复用同一 TTS。不要启动第二个 TTS。见 [文字播报接口](文字播报ROS接口.md)。

## 启动与兼容

- 2026-10-14 新增接口 `/voice/set_asr_enabled`（`std_srvs/srv/SetBool`），已部署并在小车正式语音入口验证。关闭会退出独立 ASR/VAD 进程并释放其模型内存，开启重新加载；播报、共享录音和原有 KWS 配置保留。恢复后重新唤醒，不恢复旧会话。`VOICE_ASR_ENABLED=false` 可让脚本初始不加载模型；默认 true。状态、调用及板端验证范围见 [ROS 接口使用手册 9.1](ROS接口使用文档.md#91-语音与阶段播报)。

- `VOICE_BACKEND=offline ASR_BACKEND=offline` 是默认。`ASR_BACKEND=xfyun` 只替换识别器，仍从 `/voice/audio` 读音频，凭据只放板端私有文件。
- `VOICE_BACKEND=online` 被拒绝。旧 `CONTINUOUS_ASR` 不再选择独立录音路径；本次不合入远端 `continuous_asr_node`，不增加第二个录音路径。
- C/Gemini 组合入口、必填序列号/标定、舌苔原始 RGB 和试运行相机选择见 [合并说明](远端C与语音合并说明20261012.md)。跌倒状态仍只用于感知与显示，没有新增语音或运动触发。
- 没有小车时运行 `scripts/ci_unit_tests.sh` 和隔离 ROS 测试。本地既有语音授权、ASR 和舌苔运行时测试验证会话及门禁，不接硬件。合成测试不能证明真人收音、分类准确率或制动效果。

旧连续收音、自动授权和各版本安装记录移入 [历史入口](archive/语音连续收音旧入口20260929.md)。回退应先停新入口，再恢复整套匹配的源码/构建/配置；不能把旧路由器与新保护接口混用。
