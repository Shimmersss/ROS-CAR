# SLAM、Nav2 与人体跟随绕障

本地新增 `navigation_bringup`，使用 Humble 的 SLAM Toolbox、NavFn 全局规划、DWB 局部避障和 AMCL 定位。导航作为独立可选入口，原感知 A/B 不因安装该包而切换；默认关闭运动，未标定仍可运行原相机检测/跟踪。此文档的实际验证结果见末尾，不代表实车验收。

## 链路与模式

```text
N10P /scan + 底盘 /odom → SLAM Toolbox → /map + map→odom
已有 map.yaml + /scan + /odom → AMCL → map→odom（与 SLAM 互斥）
/odom → odom_tf → odom→base_footprint
安装标定 → base_footprint→laser / camera optical frame
TargetState → 观测时刻 TF → 人前方留距目标 → NavigateToPose
NavFn + DWB → /navigation/cmd_vel_raw → 带时戳请求 → motion_guard → /cmd_vel
```

`mode:=mapping` 在线建图；`mode:=localization map:=...` 读取保存地图并等待 `/initialpose`；`mode:=external` 用于已有外部地图/定位系统及隔离测试。外部系统须提供 `/map` 和 map→odom。不要同时启动 SLAM、AMCL 或其他 map→odom 发布者。

底盘已有 `/odom`，但当前厂商节点不广播里程计 TF，且 position.z 存储航向。新增桥只发布平面 odom TF，z=0，保留消息原时间；不修改原话题。有 EKF 或其他 odom TF 发布者时，使用 `publish_odom_tf:=false`，保证每段 TF 唯一。

人体目标根据同一观测时刻的人、车地图坐标计算，默认保持 1m，距离已够近就取消目标并停车。移动超过 0.3m、间隔至少 1s 更新导航目标，先取消旧目标、收到终态后再发新目标。目标失效、目标 ID 变化、定位或里程计陈旧、导航失败都停止并要求重新启动。Astra 缺传感器时戳，默认不准参与导航；显式 `allow_unstamped_astra: true` 才接受其发布时刻近似，不能将此近似描述成严格时间同步。

Nav2 只发布原始速度，实际底盘仍由 motion_guard 唯一控制。DWB 默认前向 0.15m/s、角速度 0.5rad/s，不做倒车/旋转恢复。保护层保留全方向保守停车圆盘；Nav2 使用从 safety.yaml 推导的同等圆盘半径及额外膨胀，避免路径规划允许贴障而保护层持续拒绝。狭窄通道可能无法通过，应按实际几何、制动实验调整，不能只缩小代价地图规避保护。

## 环境与启动

在 Jetson 原生 Humble 环境准备依赖并重新编译（本轮未执行远端操作）：

```bash
sudo apt-get update
sudo apt-get install ros-humble-navigation2 ros-humble-nav2-bringup ros-humble-slam-toolbox
source /opt/ros/humble/setup.bash
cd /home/wheeltec/ROSCAR/ros2_ws
colcon build --base-paths src
```

N10P 按 `docs/N10P雷达接入.md` 构建独立雷达 overlay。感知、雷达、里程计须各有唯一来源；导航脚本不打开底盘串口、不切换 A/B、不启动现有直接跟随器。不要与 `motion_guard follow.launch.py` 或红色组合控制入口同时启动。

```bash
bash scripts/run_navigation.sh mode:=mapping
# 已在当前环境 source 雷达 overlay 后，可追加 with_radar:=true。
# 保存图像地图（拒绝覆盖已有同名文件）：
bash scripts/save_navigation_map.sh /home/wheeltec/ROSCAR/data/maps/room
# 退出建图后切换已有地图定位：
bash scripts/run_navigation.sh mode:=localization map:=/home/wheeltec/ROSCAR/data/maps/room.yaml
```

地图保存为 YAML+图像，供 AMCL 使用；不保存 SLAM pose graph，不提供继续优化历史图的承诺。AMCL 需要在 map 坐标下发布实际起点 `/initialpose`（PoseWithCovarianceStamped），不能把任意原点当作已定位。当前 AMCL 使用差速运动模型，DWB 禁用横移；底盘实际型号确认后再按轮式运动学调整。

## 标定和运动前置

复制配置到设备私有配置目录，启动时使用 `safety_config:=... follow_config:=... sensors_config:=...`，不要直接把占位值改成已确认：

- `config/sensors.yaml`：实测 laser 与 camera optical frame 相对 base_footprint 的 xyz（米）和 quaternion_xyzw。相机默认四元数仅表示常见光学轴方向，不是实际安装标定。`confirmed=false` 时不发布 TF；已有驱动提供同一段 TF 时也不重复发布。
- `config/follow.yaml`：填实际 TargetState 的 source/frame，确认相机到车体外参与里程计后才设 `camera_calibrated`、`odometry_confirmed`。默认 source=yolo，实际光学 frame 可能不同。
- `motion_guard/config/safety.yaml`：实测车体尺寸、雷达安装和制动/通信延迟，设置对应确认项。导航入口统一 guard base_frame=base_footprint，并与 follow 配置同步目标 source/frame。

未确认的参数不会妨碍之前的实际检测和跟踪；新导航运动保持拒绝。第一次应架空/空旷场地验证轮速、里程计尺度、正向/转向和 TF 方向，然后验证距离保持与故障停车，再做绕障。

运动需启动参数 `motion_enabled:=true`，再依次调用：

```bash
ros2 service call /control/arm std_srvs/srv/Trigger '{}'
ros2 service call /navigation/start_follow std_srvs/srv/Trigger '{}'
# 停止导航 / 紧急锁存停车：
ros2 service call /navigation/stop_follow std_srvs/srv/Trigger '{}'
ros2 service call /control/stop std_srvs/srv/Trigger '{}'
```

故障恢复：排除故障 → `/navigation/stop_follow` 清除导航故障并取消旧目标 → `/control/arm` → `/navigation/start_follow`。没有自动恢复运动。不要通过 Foxglove 或其他节点另发 cmd_vel。Nav2 NavigateToPose action 本身开放给 ROS，但未开始受保护的人体跟随时外部导航目标无法通过速度适配器。

## Foxglove

沿用已存在的 Foxglove Bridge；同一 ROS 域只启一个 Bridge。需要单独启动时使用现有 `scripts/run_foxglove.sh`。导入 `foxglove/navigation-layout.json`，查看地图/扫描/规划路径、局部代价地图以及 `/navigation/state`、`/control/state`、`/odom`。地图面板 fixed frame=map，局部面板 fixed frame=odom。没有 map→odom 或 odom→base_footprint 时可视化不完整属于输入未就绪，不应靠单位 TF 掩盖。

额外可在 3D 面板添加 `/global_costmap/costmap`；二维地图均为 OccupancyGrid，路径为 Path，目标为 PoseStamped，TF 使用 `/tf`、`/tf_static`。现有 Foxglove 连接地址不变。布局已生成，真实客户端显示仍需现场验收。

录包 `scripts/record_follow.sh` 已包含地图、路径、代价地图、导航状态和原始速度；回放脚本将所有白名单话题改到 `/replay/...` 并隔离 ROS 域，不向原控制/TF话题回放。

## 验证

`bash scripts/test_navigation_container.sh` 安装真实 ARM64 Humble Nav2/SLAM 环境，执行构建、几何测试、合成房间 SLAM、真实 NavFn/DWB/BT 及桥接故障注入；日志写入 `artifacts/navigation-test.log`。最终结果记录 WORKLOG.md。合成输入不构成真实雷达、实车避障、里程计或相机外参验收。

实现参考：[Nav2 Humble 配置](https://github.com/ros-navigation/navigation2/blob/humble/nav2_bringup/params/nav2_params.yaml)、[SLAM Toolbox](https://github.com/SteveMacenski/slam_toolbox/tree/humble)。
