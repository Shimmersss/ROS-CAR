# 连续语音控制：使用与回退

更新时间：2026-09-29。本页描述 Qwen3-ASR + Silero VAD + 固定规则控制的当前入口；旧的逐轮收音实现保留用于回退。

## 使用方式

1. 说“小微小微”，听到“我在”后直接说“前进”“左转”“停一下”等指令。首次明确的方向口令会自动请求 `EXTERNAL` 模式、等待新鲜状态、调用 `/control/arm`，再等待 `/control/state` 确认 `ARMED` 后执行同一条指令。任何一步失败都不发非零速度。“开始遥控”仍可作为可选口令。
2. 再说“小微小微”只刷新会话，不会退出或让车继续运动。会话无新语音 30 秒后结束，并撤销授权。
3. “停止”“停一下”请求停车、撤销运动授权，但保留语音会话；随后可直接说下一条方向口令，路由器会重新授权。“急停”“退出遥控”“退出语音控制”停车并结束会话；之后需要再次唤醒。
4. 每条运动口令最多执行 2 秒；无新请求时速度归零。语音停车需等待 VAD 分句和 ASR 解码，不能代替实体急停或底盘看门狗。

常见同义词包含“往前走”“向前走一点”“再左转一点”“停一下”。“一点”对应 1 秒。否定、疑问和含糊的运动说法仍会被拒绝；没有使用大模型猜测动作。

ASR 偶尔输出“嗯”“真”等未匹配固定指令的文本，或把运动词识别成含糊说法时，路由器只记录日志并静默忽略；语音会话继续监听，不播放指令列表或错误提示。明确识别到的有效动作若被控制门禁拒绝，仍会播报失败原因。

## 收音链路

`continuous_asr_node` 长时间保持一个 `arecord` 采集进程。路由器是唯一会话管理者，通过带 transient-local QoS 的 `/voice/session_active` 通知 ASR；ASR 在会话外和 TTS 播放时继续读取麦克风，但不送入识别。Silero VAD 以 512 样本窗分句，当前结束静音为 0.7 秒。收音线程与 Qwen3 解码线程分开，后一句可以在前一句解码期间继续采集。

识别队列最多容纳两句；队列溢出时结束会话并请求停车。每句带会话代次和结束时间，退出会话或结果超过 6 秒时丢弃，避免旧指令迟到执行。TTS 播放后有 0.2 秒回声冷却。方向指令成功不逐条播报，减少播放期间的收音空窗。

模型放在 `/home/wheeltec/ROSCAR-offline/models/silero_vad.onnx`，来自 [sherpa-onnx 官方发布资产](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/silero_vad.onnx)；本次 SHA-256 为 `9e2449e1087496d8d4caba907f23e0bd3f78d91fa552479bb9c23ac09cbb1fd6`。Qwen3-ASR 仍为 CPU 两线程，本次没有更换模型或使用 CUDA。

## 验证与回退

- 在独立 ROS 域先运行 `scripts/test_voice_session_isolated.py`，它只启动路由器和假的 guard 服务，不连接真实底盘。测试包括首条方向口令自动授权、重复唤醒、停止后再次授权、急停退出、会话外拒绝，以及 guard 未确认 `ARMED` 时不发布非零速度。
- 音频重放需验证两句之间 0.8 秒停顿时都被完整分句，并检查 ASR 日志的 `audio_s`、`decode_s`、`age_s`。真人麦克风识别率、噪声环境和实体动作需要现场验收。
- 若连续收音有问题，设置 `CONTINUOUS_ASR=false` 并重启语音入口，使用保留的旧 `asr_node` 和逐轮监听；若本地 Qwen3 不合适，设置 `ASR_BACKEND=xfyun` 切回讯飞。两种回退仍使用同一套固定规则控制。此次改动前备份为 `/home/wheeltec/ROSCAR-backups/continuous-voice-20260929-192944/before.tar.gz`（SHA-256：`460409fba541dd5b05e4af8633080dfd27c72089a4086b221f3b93c0fdcaeb34`）。
