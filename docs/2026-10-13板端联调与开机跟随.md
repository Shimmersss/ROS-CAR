## 负载优化及测量

保持 Qwen3-ASR CPU2 与 MeloTTS。移出未使用的辅助节点；图像只保留最新未读帧；推理忙时跳过的有效相机帧仍参与连续性判断，避免把推理变慢误作相机断流。真实断流/回拨/输入变化仍使旧轨迹失效，旧推理结果不恢复为有效位置。

进程内配准显式 `GEMINI_REGISTRATION_BACKEND=cuda`，float64 投影与 z-buffer，8 组合成场景输出与 NumPy 逐像素一致。深度补洞只为可填的缺失像素求最多 9 邻域样本中位数，保持测距结果；同一合成区域测量均值 47.5→15.3 ms。

ReID 显式使用本机生成的 `osnet_x1_0_msmt17-fp32.engine`。TensorRT FP32/禁用 TF32，复用 Pose Python，独立 CUDA stream；6 种合成裁剪的归一化特征最大误差约 4.7×10⁻⁶。单独 CPU 模型约 109 ms、TensorRT 约 13–16 ms。引擎及来源 ONNX 的哈希/架构/预处理均验证，缺环境/不匹配直接拒绝，不回退或自动下载。

```bash

bash scripts/build_reid_engine.sh \
  models/weights/osnet_x1_0_msmt17.onnx \
  models/weights/osnet_x1_0_msmt17-fp32.engine
# 在已有 Pose Python/CUDA 环境中核对真正的 GPU 后端：
PYTHONPATH=ros2_ws/src/yolo_person_tracker "$YOLO_PYTHON" tests/test_registration_cuda.py
PYTHONPATH=ros2_ws/src/yolo_person_tracker "$YOLO_PYTHON" tests/test_reid_tensorrt.py
```
