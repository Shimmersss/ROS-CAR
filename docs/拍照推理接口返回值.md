# 拍照推理接口返回值

2026-10-16按车端当前overlay的 `RunInspection.srv` / `CaptureTask.action`、常驻服务参数，以及本轮真实Gemini三次结果核对。当前服务是 `/inspect/tongue`、`/inspect/helmet`、`/inspect/pcb`，通过WSL GPU分析；面诊无模型。当前HTTP bridge关闭，结果直接返回ROS调用方。

## 1. ROS原始返回与保存文件不是同一种外壳

`capture_task_interfaces/srv/RunInspection`：

```text
# 请求
string task_id
string announce
float64 prepare_sec
float64 timeout_sec
---
# 响应
bool success
string status
string detail
string task_id
string capture_id
string result_json
sensor_msgs/CompressedImage annotated_image
```

| 字段 | 真实含义 |
|---|---|
| success | 只有任务status=analyzed为true；检测出缺陷/未佩戴也可为true，不能用它判断合格 |
| status | analyzed、retake、failed、cancelled、rejected；门面还可返回busy、unavailable、invalid、timeout |
| detail | 原因码；正常analyzed常为ok，无舌体为retake；早期失败可能无分析JSON |
| task_id / capture_id | 任务和选中图片的ID，需与JSON内部匹配；采集前失败时capture_id可为空 |
| result_json | **字符串**，需 `json.loads(response.result_json)`；去掉JPEG base64后的网关对象 |
| annotated_image.format / data | analyzed时format=jpeg，data是JPEG字节；与result_json中SHA256/宽高一致；失败或retake时无JPEG |
| annotated_image.header | 当前实现保留默认stamp=0、frame_id为空，不能把它当原相机采集时间或坐标系；以task_id/capture_id和哈希关联 |

`result_json`解析后的公共字段：status、task_type、request_id、task_id、capture_id、model、image、result、summary、annotated_image、timings_ms。当前网关不在结果JSON内回显robot_id或capture_time，虽然请求要求这些信息。`model`包含ready、权重/冻结摘要、device，以及后端特有的classes/thresholds或pipeline_digest/labels。

脚本 `scripts/inspect_client.py` 保存的 `result.json` 则含 `analysis` 对象：它是已经解析的 `result_json`，不是ROS额外新增的analysis字段。脚本把JPEG另存为 `annotated.jpg`，不在JSON里重复存字节。

真实保存格式样例（不含实拍图像，不修改现场分数/检测框）：[舌诊](examples/inspection/tongue.saved.json)、[安全帽](examples/inspection/helmet.saved.json)、[PCB](examples/inspection/pcb.saved.json)。这些是2026-10-16的固定记录，ID、分数、耗时会随下一次请求变化；房间场景没有标准实物，不证明准确率。

## 2. 舌诊

正常实际分类时，`analysis.result`包含：

- pipeline_id / pipeline_digest：冻结passthrough_debug版本及摘要。
- classification_performed：是否真的运行分类；不能只看summary.count。
- labels：八个键，每项有score、threshold、decision（positive/negative/uncertain）；positives只列positive项。
- quality：passed、failures、retake_hints、measured、unmeasured_gates；不能把未测项称为通过。
- roi：分类时含原图区域信息，例如box_original；未找到舌体时可为null。

八标签为TonguePale（舌色偏淡）、TipSideRed（舌尖/边红）、Spot（红点）、Ecchymosis（瘀斑）、Crack（裂纹）、Toothmark（齿痕）、FurThick（厚苔）、FurYellow（黄苔）。是舌象特征，不是疾病诊断。

本轮真实无舌体返回：外层success=false/status=retake/detail=retake；内层status=retake、classification_performed=false、labels={}、positives=[]、quality.passed=false、failures中gate=empty_mask、roi=null、annotated_image=null；ROS图片数据为空。**labels={}表示没有分类，不是八项阴性。** 当前模型device=cuda；weights_sha256此处是整个pipeline摘要，不是单个 `.pt` 的SHA256。

## 3. 安全帽

`analysis.result`：

```json
{
  "detections": [{"cls": 1, "name": "no_helmet", "score": 0.8144988417625427,
    "xyxy": [189.30718994140625, 358.16351318359375, 355.29888916015625, 479.88885498046875]}],
  "helmet_count": 0, "no_helmet_count": 1, "violation": true,
  "conf_threshold": 0.45, "iou_threshold": 0.45, "imgsz": 640
}
```

本轮success=true、外层status=analyzed、内层status=ok，返回640×480 JPEG。类别0=helmet、1=no_helmet；计数是检测框数量，不是经过人员身份去重的人数。xyxy是原图像素浮点坐标。`summary`为positive=true/count=1/text_key=helmet_violations。没有检测框时计数为0、violation=false，**不能据此证明画面中的每个人都佩戴合规**。

## 4. PCB

`analysis.result`字段为defects（每项cls/name/score/xyxy）、reject（是否存在疑似框）、conf_threshold=0.2、imgsz=640。**PCB实际result没有iou_threshold字段**；model.thresholds里仍报告iou=0.45。

| cls | name | 中文 |
|---|---|---|
| 0 | missing_hole | 缺孔 |
| 1 | mouse_bite | 鼠咬 |
| 2 | open_circuit | 开路 |
| 3 | short | 短路 |
| 4 | spur | 毛刺 |
| 5 | spurious_copper | 余铜 |

本轮房间场景返回2个疑似框（spurious_copper、missing_hole），外层success=true/status=analyzed/detail=ok，内层status=ok、reject=true，summary.count=2；不是标准PCB验收。模型输入imgsz=640不会把原640×480图片改写成640×640返回；真实image及JPEG均640×480，超大图才按最长边1280等比缩小标注。

## 5. 状态、图片和播报

- 网关ok/uncertain → 任务analyzed，返回标注图；uncertain仍需查看各项decision，不等于所有特征确定。
- 网关retake → 任务retake，保留重拍原因，不返回标注图。
- model_unavailable/busy/timeout/invalid_input/error → 任务failed，detail说明原因。取消、超时、租约/安全清理失败也不能返回成功标注图。早期拒绝或超时可能没有result_json。
- JPEG二进制只在ROS的annotated_image.data中；JSON中annotated_image只有content_type/width/height/sha256。用SHA256核对收到字节，不能只检查format字符串。
- timings_ms是网关排队/解码/推理/标注时间，不含小车的完整播报、准备和采集；本轮三任务完整耗时22.05/16.94/24.43秒。
- 结果播报由小车固定模板生成，复用唯一TTS队列；不直接朗读任意模型文本。用户已现场确认语音恢复正常，本次不把无标准素材的链路检查称为准确率验收。

取消对应 `/inspect/cancel`，只取消本ROS门面拥有的匹配任务。HTTP桥接的analysis event和单独JPEG回传仅在显式启用bridge时发生，见[云端协议](云端拍照任务接口协议.md#9-显式-infer-模式分析结果与标注图)。迁移云端机器与修改端口见[部署迁移说明](云端推理部署与迁移.md)。
