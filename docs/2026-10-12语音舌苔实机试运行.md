## 使用与管理

先说“小微小微”，等“已唤醒，请说指令”播完，再说“查询状态”或“舌苔检测”。检测时按播报正对相机伸出舌头，保持到拍摄完成。结果后可以说“重新拍照”“播报上次结果”“退出舌苔检测”；超出普通会话窗口先重新唤醒。退出始终保持未授权，不恢复跟随。完整口令见[语音控制使用说明书](语音控制使用说明书.md)。

以下命令在以 `wheeltec` 登录的小车终端执行：

```bash
systemctl --user status roscar-voice-tongue-trial.service --no-pager
systemctl --user stop roscar-voice-tongue-trial.service
systemctl --user start roscar-voice-tongue-trial.service
journalctl --user -u roscar-voice-tongue-trial.service -n 50 --no-pager
tail -n 80 /home/wheeltec/ROSCAR-voice-tongue-20261012-066c2ad/artifacts/trial/voice.log
```

共享录音、路由、TTS、guard 和相机各启动一份，不叠加旧服务。新版服务停止会先请求停车，然后通过 systemd cgroup 清理全部子进程，12 秒超时后兜底强制终止。服务异常不自动重启，需检查 `artifacts/trial/*.log`。

只读检查不发运动指令，不保存音视频：

```bash
cd /home/wheeltec/ROSCAR-voice-tongue-20261012-066c2ad
source /opt/ros/humble/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=182 ROS_LOCALHOST_ONLY=0
python3 scripts/check_voice_tongue_runtime.py --seconds 10
```

原服务备份目录为 `/home/wheeltec/ROSCAR-backups/voice-tongue-trial-20261012-066c2ad`。旧 `roscar-robot.service` 已停止并禁用开机启动，其退出码显示 failed，但已核对旧子进程退出。旧入口含自动授权/运动开启参数，因此回退不能直接重启旧服务；应先停止新服务，核对旧入口改为运动关闭、禁止自动授权且与对应版本参数兼容，再受控启动。密码、凭据及舌图不进入 Git；本次默认 `save_images=false`，检测 JSON 仍按模块配置保存在车端私有状态目录。
