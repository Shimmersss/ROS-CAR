# 语音混合方案：部署与回退

> **当前入口（2026-09-29）**：Qwen3-ASR 0.6B INT8（本地 CPU 两线程）+ Silero VAD 连续收音 + 固定控制规则 + 本地 MeloTTS，不启动聊天节点或 Ollama。`VOICE_BACKEND=offline ASR_BACKEND=offline CONTINUOUS_ASR=true` 为默认值。新交互、验证和回退说明见 [连续语音控制与回退](连续语音控制与回退.md)。若需临时回退逐轮收音，设置 `CONTINUOUS_ASR=false`；切回讯飞识别则设置 `ASR_BACKEND=xfyun`。前一版备份：`/home/wheeltec/ROSCAR-backups/qwen3-asr-20260929-145122/before.tar.gz`。以下早期部署记录保留用于追溯。

## 当前语音入口与回退

项目总入口通过 `scripts/start_project.sh` 启动 `scripts/run_voice_assistant.sh`，默认启用离线 ASR。离线 launch 的 `/offline_asr` 参数 `asr_backend` 应为 `qwen3`。该模型通过 sherpa-onnx CPU 执行；板上 CUDA wheel 与 JetPack 6.2 不兼容，本次没有启用 CUDA。五条录制播报样例的单句解码用时 1.64–2.21 秒；真人现场识别效果尚待测试。

如需恢复讯飞 ASR，在车上的私有运行环境设置 `ASR_BACKEND=xfyun`，然后通过既有项目服务重启入口加载；其他固定规则控制和本地 TTS 保持当前配置。若要撤销本次全部文件变更，停止项目服务后从上述 `before.tar.gz` 恢复本次备份文件，再重建 `offline_voice` 并启动服务。切换前确认当前口令和控制状态；不要同时运行两套语音节点。下面的历史说明涉及此前 SenseVoice、FireRedASR2、讯飞与 Ollama 的阶段配置。

## 隔离目录和模型

Orin Nano JetPack 6.2 上将依赖放在 `/home/wheeltec/ROSCAR-offline`，避免覆盖 `/home/wheeltec/ROSCAR-current`：

- `venv/`：sherpa-onnx 1.13.8 的 ARM64 Python wheel；使用 `--system-site-packages` 复用 ROS Python 依赖。
- `models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17/`：默认 SenseVoice Small INT8 ASR，固定中文、CPU 两线程。
- `models/sherpa-onnx-streaming-paraformer-bilingual-zh-en/`：保留原 Paraformer ASR，供回退。
- `models/vits-melo-tts-zh_en/`：中英 TTS。
- `ollama/`：Ollama 0.34.0 Linux ARM64 主包与 JetPack 6 附加包，独立于原有 `/usr/local/bin/ollama`。
- `models/ollama/`：预先拉取的 `qwen3:1.7b`。运行时只绑定 `127.0.0.1:11435`。
- `project/install/`：从本分支构建的 `xfyun_speech`、`deepseek_ros2`、`voice_command_router` 和 `offline_voice` 隔离 overlay。前两个包在离线入口中只提供已有的队列、唤醒和工具处理基类；不会调用它们的云端请求方法。单独构建 V5.1 版本可避免引用车上旧安装层中仍有的蜂鸣器工具。

ASR/TTS 模型来自 [sherpa-onnx Paraformer 模型页](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/online-paraformer/paraformer-models.html)、[MeloTTS 模型页](https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/vits.html)；Ollama 来自 [官方 v0.34.0 发布页](https://github.com/ollama/ollama/releases/tag/v0.34.0)。ASR/TTS 下载归档的 SHA256 分别为 `5462a1fce42693deae572af1e8c4687124b12aa85fe61ff4d3168bb5280e205f`、`e58351ed7149f290a54534538badd4077cdbe6fddc964b24d0bee870415d1514`；Ollama ARM64 主包和 JetPack 6 附加包分别为 `6a9e5b3650c2024d8a78da86b23876f6eea238657a3262d7e5ec0f3688c5d28e`、`6e2e74cd9cacff09f1376bc6725ccadd3ac4828018b8c4e3356cf6dab7a1904b`。车上 Qwen3 模型为 `qwen3:1.7b`、Q4_K_M，Ollama 摘要 `8f68893c685c3ddff2aa3fffce2aa60a30bb2da65ca488b61fff134a4d1730e7`。模型及二进制不提交到 Git。

准备好这些官方归档后，在 Jetson 的隔离目录安装：

```bash
offline_root=/home/wheeltec/ROSCAR-offline
mkdir -p "$offline_root/models" "$offline_root/ollama"
python3 -m venv --system-site-packages "$offline_root/venv"
"$offline_root/venv/bin/pip" install sherpa-onnx==1.13.8 sherpa-onnx-bin==1.13.8
tar -xjf sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2 -C "$offline_root/models"
tar -xjf sherpa-onnx-streaming-paraformer-bilingual-zh-en.tar.bz2 -C "$offline_root/models"
tar -xjf vits-melo-tts-zh_en.tar.bz2 -C "$offline_root/models"
tar --zstd -xf ollama-linux-arm64.tar.zst -C "$offline_root/ollama" \
  --exclude='lib/ollama/cuda_v12' --exclude='lib/ollama/cuda_v13'
tar --zstd -xf ollama-linux-arm64-jetpack6.tar.zst -C "$offline_root/ollama"
```

联网准备阶段在本机 11435 端口运行该 Ollama 版本并拉取 `qwen3:1.7b` 到 `models/ollama`；`ollama list` 确认模型后即可断网运行。模型拉取完成后停止准备阶段的 `ollama serve`，正式语音脚本会自行管理它。

完成识别、合成、LLM 工具、内存和时延测试后，才可把分支文件同步到正式项目并重启项目。正式环境务必让同一时刻只有一个语音 launch 占用唤醒串口和话题。验证时先保持 `voice_control_enabled:=false`；车辆动作测试需在清空场地、可人工急停的条件下执行。

## 回退

如果离线语音在正式项目出现故障，设置 `VOICE_BACKEND=online` 后重启语音或项目入口，原讯飞/DeepSeek 链路和凭据文件仍可用。若需要完全恢复到 V5.1 源码，停掉新语音进程，把 `scripts/run_voice_assistant.sh`、`scripts/start_project.sh` 从 V5.1 `c84d838` 还原，保留或删除额外的 `offline_voice` 包均不会改变旧在线 launch。正式目录已经部署离线方案，完整回退应使用部署前备份。离线模型和二进制均在 `/home/wheeltec/ROSCAR-offline`，确认不再被运行入口使用后才可移除该目录。


## 2026-09-29：SenseVoice ASR 更新

模型来源：[sherpa-onnx 官方 SenseVoice 模型说明](https://k2-fsa.github.io/sherpa/onnx/sense-voice/pretrained.html)。模型下载需要联网，推理完全在本地进行。
