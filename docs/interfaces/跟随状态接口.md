# 跟随状态观察接口

`/control/follow_state`，类型 `std_msgs/msg/String`，正文为 JSON。由 person_follower 发布：原因改变时立即更新，原因不变约每秒一次。仅供诊断，不能作为运动授权或最终车速；最终速度仍读 `/cmd_vel`，授权仍读 `/control/state`。

| 字段 | 含义 |
|---|---|
| reason | target_invalid_or_stale / not_authorized / fall_paused / within_follow_distance / outside_forward_half_plane / following |
| target_id | 当前目标 epoch:track_id；没有目标为空 |
| distance_m、bearing_rad | 跟随器接受的目标距离和光学偏角；目标不可用时为 null |
| target_distance_m | 期望保持距离；demo 仍为1.3米 |
| ackermann | 本次是否使用阿克曼弧线控制 |
| linear_mps、angular_rps | 本次跟随器请求，不是底盘实测速度 |

```bash
ros2 topic echo /control/follow_state
```

数据基于现有 TargetState，不把躯体代表点距离改成后轴距离或地面接地点。fall_paused 可由无效/过期告警引起，不等于发生了确认跌倒。录制脚本保存本话题，最终 guard 仍可能拒绝该请求。
