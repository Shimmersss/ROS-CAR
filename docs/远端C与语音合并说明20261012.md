# 远端 C/Gemini 与本地语音合并说明

2026-10-12，本地合并。远端基线 `origin/main=563ed5e`，本地基线 `513b240`，备份分支 `backup/local-main-before-remote-20261012`。本轮不部署、不重启小车、不推送远端。

## 合并选择

- 保留远端 Gemini Pro 独立驱动/标定、C 骨架和跌倒规则、深度融合、地面与统一定位、三维姿态、ReID、云台桥接、录制评估工具、CI 和文档归档。
- 按用户明确要求，语音实现、配置、模型、固定规则、8 秒会话、共享录音、常开 KWS、显式 epoch 授权及原 TTS/SayText 接口均采用合并前本地版本；不合入远端独立连续录音实现、自动授权或对应旧会话测试。
- 舌苔模式只补充相机连接：launch 接受 `camera_topic` / `camera_profile`，C 组合入口默认取 `/camera/color/image_raw`，携带 `gemini_rgb_tongue_v1` 元数据。C 感知仍使用其配准后的图像与相机信息，两者不混用；没有改变舌苔云端冻结版本或结果契约。
- 舌苔试运行默认选择 Gemini；显式 `TRIAL_CAMERA_BACKEND=astra` 可使用原 RGB-only 兼容入口。它与 C 组合入口二选一，避免重复占用相机、录音和保护层。
- 运动默认关闭、禁止自动授权，所有安装/地面/重力/制动确认仍须实测。跌倒状态不自动触发语音或运动。

## 新 Gemini：C 感知加原语音

在小车的合并副本根目录执行 `colcon build --base-paths ros2_ws/src` 生成 `install/`，并按 `scripts/build_gemini_camera.sh` 准备独立 Gemini 驱动、Pose engine 和离线语音依赖后：

```bash
export GEMINI_SERIAL=AY2755200PW
export GEMINI_CALIBRATION="$PWD/ros2_ws/src/perception_bringup/config/gemini_AY2755200PW.json"
bash scripts/start_c.sh
```

这是相机、C 感知、Foxglove 加原语音。默认不启底盘、不启跟随、不启舌苔。标定文件必须对应实际相机；换设备不能沿用该序列号文件。板端 RGB 640×480 模式与 Mac 录制的高分辨率裁剪方案不同，偏蓝、颜色一致性及配准需现场检查。

## 再接入舌苔流程

有车且串口驱动已经构建时，在同一 C 总入口显式设置：

```bash
WITH_TONGUE_MODE=true WITH_FOLLOWER=true WITH_CHASSIS=true \
SERIAL_PORT=/dev/wheeltec_controller CAR_MODE=mini_akm \
MOTION_ENABLED=false bash scripts/start_c.sh
```

上述命令沿用前面的 Gemini 环境变量。`WITH_FOLLOWER=true` 提供现有唯一 guard；运动关闭时舌苔仍可申请停车保持。robot 模式必须有真实静止里程计，不能用 bench 代替车辆安全条件。无车软件演练可设 `TONGUE_SAFETY_PROFILE=bench WITH_CHASSIS=false`，运动必须关闭；仍需相机/模型运行环境。

`TONGUE_CAMERA_TOPIC` / `TONGUE_CAMERA_PROFILE` 可显式覆盖；`TONGUE_SERVER_URL` 指定已配置的冻结版本服务。不要把检测框画面当原始舌苔图片。舌苔就绪后按 [说明书](语音控制使用说明书.md) 唤醒、检测、重拍或退出。

## 专用运动关闭试运行

`run_voice_tongue_trial.sh` 继续由原用户服务监督，默认 Gemini，要求服务环境包含 `GEMINI_SERIAL`、`GEMINI_CALIBRATION`（unit 读取 `~/.config/roscar/voice-tongue-trial.env`；安装时还需把 ExecStart 改为合并副本的绝对路径）；它启动相机、真实底盘回传、唯一 guard、原语音、舌苔及 `/voice/say` 桥接，不需要 Pose engine。不叠加整车或 C 总入口。旧已部署副本不会随本地 Git 合并自动更新。

如需在 C 总入口上提供文字播报接口，原语音须开启 SpeakText（舌苔启用时已有），再独立运行 `ros2 launch roscar_api speech_api.launch.py`；不要传 `with_tts:=true` 启动第二个 TTS。见 [接口文档](文字播报ROS接口.md)。
