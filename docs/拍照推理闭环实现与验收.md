## 实现边界

`pipeline_mode=upload` 默认保持原来的拍照上传链路；`infer` 显式配置网关 URL，服务门面改为 `/inspect/*`，上传模式仍为 `/capture/*`，同一个入口不会同时注册两套服务。Action 增加结果 JSON、标注图，调用方和接口包必须一起重新编译。

推理链为准备播报完成 → 等待 → 新鲜原始 RGB → 质量检查、选最清晰帧 → 网关模型 → 验证 ID、结构、JPEG/SHA256/尺寸 → 固定短句播报 → 结果返还 → 释放停车租约。网关不接入 ASR、语音舌苔模式或速度控制。运动安全机制保持原有逻辑。

云端指令通过原桥接接入：先返回含 `analysis` 的最终 event，再由独立的有界图片队列上传 `/v1/tasks/{task_id}/result-image`。图片失败重试有上限，不阻塞新指令轮询。默认只传标注图；只有显式 `return_original_image=true` 才经内部非持久 ROS 话题转发原图，不默认落盘。原来的 `/images` 仅用于 upload。

舌诊代理只接受 `cloud_r50_384_cvAC10_passthrough_debug` 和摘要 `1a897fa5…aef1`，八标签保持原包契约。已有语音 `tongue_mode` 使用另一个冻结版本，两条入口独立，本轮不替换它的模型或摘要。

## 暂停点与续跑

指南 §4.3 写明：“通过标准：8 个标签逐项 |Δscore| ≤ 1e-3，所有 decision 一致，status 一致。不通过就停下来报告，**不要**擅自改阈值。”复核前已额外运行 CPU 参考链路，已如实保留诊断结果；复核后停止相关测试服务，等待用户选择是否允许原版本 CPU 替代。该选择未收到前，不继续舌诊接入或把 A2 标为通过。此约束已写入定时续跑提示。

临时网关与 CPU 舌诊进程、SSH 18200 转发已经停止；WSL 与本地临时 token、转发 key、临时 authorized_keys 条目均已清理，8200/8096/18200 监听关闭。模型、venv、私有路径配置和诊断报告保留在 WSL；若获准继续，需要重新生成私有 token/受限隧道。`gateway.private.yaml` 暂移除了 tongue 配置，候选 CPU 配置仅保存在 `gateway.pending-cpu.private.yaml`，不得未经确认启用。

仍待：用户决定 CPU 舌诊替代方案；开发机接入 Gemini 后的 B3 新鲜采集；B4 车端独立授权和实机验收。无照片或无相机时不得伪造通过；已通过的软件测试无需因定时续跑而重复。
