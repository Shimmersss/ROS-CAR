## M1：公共输入与观测

- 确認实物相机、USB 标识、JetPack/ROS/CUDA、SSH。
- RGB、深度、内参稳定输出；验证配准、编码、单位和时间对应。
- Foxglove 图像/深度展示，记录已知距离和端到端延迟。

## M2-A：原厂骨架路线

- [x] 验证 Astra SDK ARM64 运行库和真实骨架输出；授权提示仍待厂商解释。
- [x] 仅读取并检查 bodylist；未启动含底盘的整体跟随 launch。
- [x] 适配坐标、未知采集时间、状态、无效值和超时。

## M2-B：优先推进 YOLO 路线

- person 检测 + 输入 header → ByteTrack → 选人/锁定/丢失。
- 对齐深度躯干采样、有效率、稳健统计、反投影。
- 统一目标状态和可解释诊断字段，按需补位置滤波。

## M3：A/B 对比与优化

- 同条件测试正/背/侧面、多人交叉、遮挡、同色衣服、断流。
- 比较漏检、ID 切换、距离偏差/抖动、恢复行为、GPU/内存与延迟。
- 按证据决定 TensorRT、s 版、Pose、分割、ReID，而非默认叠加。
