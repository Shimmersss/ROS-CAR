# Vendor radar and lidar packages

Copied from `JP6.2_wheeltec_ros2_src_20260903/` for hardware-specific integration.

This directory is intentionally excluded from the default colcon workspace by
`COLCON_IGNORE`. It contains Wheeltec radar, LS LiDAR, LD LiDAR, RPLIDAR,
pointcloud-to-laserscan, and dual-lidar fusion packages. No device model,
serial port, message dependency set, or runtime behavior has been validated on
the current vehicle yet.
